# Codex Dock Android

Dock-owned Activity, computer list, settings, branding and build integration.
Reuses Android WebView, file, pairing and notification helpers from Codex Mobile
Bridge, commit 0721aa7dafa6177751ba7e568e0ad0efee05655b (MIT).
The original MIT license and attribution are included as UPSTREAM-LICENSE.txt
and UPSTREAM-NOTICE.md. QR decoding uses ZXing Core 3.5.3 (Apache-2.0);
menu icons use Lucide 0.468.0 (ISC), see the bundled upstream notice.

This APK contains no Firebase SDK. Optional task alerts use the authenticated
gateway connection and a user-enabled Android foreground notification service.
