# Codex Dock 0.12.0

恢复可选的“官方账号 + 独立模型入口”，保留默认 PAT / API 直连和 0.11.0 的保存修复。

- 混合模式保留官方登录身份；模型请求使用单独加密保存的 PAT / API Key，不自动消耗官方推理额度补位。
- 新路由保持内置 `openai`，旧 `codex_config_mixed` 入口用于历史会话兼容。已保存的旧连接可升级或显式切换直连。
- 恢复原生 Codex 浏览器登录，结果先暂存，保存时才应用。当前支持文件凭据，其他存储方式给出提示。
- 网关成为独立后台进程，关闭编辑器后继续运行；支持显式启停、健康检查、协议版本检查和单实例。
- 修复会话头转发、模型目录兼容和错误诊断；保留上游状态、经过筛选的错误码与请求 ID。
- 上游鉴权失败不会触发官方令牌刷新。HTTP / SSE 支持取消与空闲超时，WS 不支持的握手响应交由原生客户端决定回退。
- 混合界面按需展开，固定保存栏、Ctrl+S、获取模型期间保存和离线保存保持。

当前线路的两轮回复、压缩和函数调用已验证；WebSocket 返回 426，原生 app-server 在启用 WS 后完成了两轮调用。Fast 参数路由已验证，实际加速及计费未验证。完整桌面客户端、真实官方账号工具和其他供应商需分别验收，详见 [审查说明](review-0.12.0.md)。

更新前退出正在使用本地网关的 Codex，并从托盘退出旧版工具；安装器会关闭旧程序。更新后打开工具，再完全重启 Codex。混合模式退出编辑器不会停止网关，显式停止会中断使用该连接的请求。重登 Windows 后打开工具或启用开机启动。

保存前自动创建加密备份，可在“模板与备份”恢复上次配置；如之后由 Codex 刷新了登录，恢复会拒绝覆盖变化，应先重新读取并核对。切回直连使用填写的 PAT / API Key；账号认证方式随直连配置改变。
