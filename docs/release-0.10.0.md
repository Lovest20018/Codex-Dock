# Codex Dock 0.10.0

首个 GitHub 正式发布版本，2026-10-28。

- 完整收录 Codex Dock 新界面、名称备注、PAT / API Key 与官方账号 + API 双模式、系统代理、本地网关、托盘及开机启动。
- “应用设置与帮助”新增 GitHub 更新：检查正式版、下载安装器、校验 SHA-256、安装并退出。更新来源固定为 `Lovest20018/Codex-Dock`。
- 只在点击“检查更新”时访问 GitHub。不会上传 Codex 配置、PAT、API Key、官方登录凭据或备注。
- 安装前处理未保存草稿并停止网关；失败保留窗口，可重新启动网关或重试。不会在后台静默覆盖程序文件。
- 便携版也可下载安装器；安装器会提供安装路径选择。需继续使用纯便携方式时，可在 GitHub 发布页下载便携 ZIP，退出旧版后解压到新目录。
- 用户的 `auth.json`、`config.toml`、加密连接、备注与备份不进入 Git 仓库或发布包。测试截图也不随发布包上传；源码中保留的示例凭据均为虚构数据。
- 发布提供安装器、包含 .NET 运行时的便携包、源码包及 `SHA256SUMS-0.10.0.txt`。

升级：从托盘退出旧版后安装，或解压新便携包。已有配置目录、加密标识、备份与模板库保持兼容。更多使用说明见 README。

此版经核心回归、发布 EXE 的隔离 UI 检查、安装后文件校验和卸载检查；未注销/重启 Windows，DPI 通过布局缩放模拟。更新安装器通过校验后由用户点击安装，GitHub 网络不可达时可重试或手动下载。
