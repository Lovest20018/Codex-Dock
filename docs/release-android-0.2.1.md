# Lovest Code Android 0.2.1

根据手机截图调整聊天列表、聊天标题、输入区和模型设置的比例。聊天列表使用浅底搜索框、紧凑的新建按钮和分隔行；聊天标题与项目路径分两行，防止两者争抢宽度。底部导航增加聊天、电脑和个人图标。

输入区简化模型工具条，将发送方式和工作模式并排排列，提醒、Skill 和权限放入下一行。展开区域限制高度并可以滚动，保留消息框与发送操作。模型设置改为圆角底部面板，统一模型行、思考强度、刷新和应用按钮的尺寸；横屏和大字体下允许面板内部滚动。

页面样式随 APK 注入，与 Windows Dock 0.15.1 兼容。现有聊天、草稿、发送和服务端协议保持原有实现。沿用包名、签名与 Logo，versionName 0.2.1 / versionCode 4，可从 0.2.0 覆盖安装。

独立测试 APK 提供示例聊天和模型数据，仅用于检查生产页面的呈现与尺寸；生产 APK 不包含这些数据或测试入口。验收记录见 [Android 0.2.1 审查](review-android-0.2.1.md)。
