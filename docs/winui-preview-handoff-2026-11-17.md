# Windows 预览交接与换机验收

本轮将已完成本机验收的 WinUI 程序整理为可解压运行的预览 ZIP。程序版本仍为 0.18.0；它包含尚未正式发布的新版界面，不能用版本号单独区分预览和既有正式版，需同时核对文件 SHA-256 与本轮校验清单。

## 解压运行

1. 完整解压到独立文件夹，保留 `app` 内所有文件和 `mobile` 子目录。
2. 从托盘明确退出旧 WinUI 预览，再运行 `app/CodexDock.WinUI.exe`。原 WPF 不会因解压而被替换。
3. 预览依赖 Windows x64、.NET 8 和 ASP.NET Core 8 运行时；Windows App SDK 随包提供，.NET 和 ASP.NET Core 运行时不包含在本预览 ZIP 中。已有 .NET 8 SDK 的本机已验证可运行。
4. 未指定配置目录时按现有 `CODEX_HOME` 或用户 `.codex` 读取。试用副本应自行明确选择独立目录。此处“可解压运行”指程序部署方式，不表示用户配置也被自动隔离到程序目录。
5. 页面修改先保留为各自草稿，按显示范围确认保存；实际应用、重启与设备授权仍走原确认。窗口关闭通常收起到托盘，网关能在 Dock 正常退出后独立运行。

恢复使用旧版时先停止本次启动的模型/手机网关并退出新版，再打开旧版。若已经保存配置，应使用应用内对应备份核对恢复差异；重新打开旧程序本身不会自动回滚配置。

## 包内说明

`START-HERE.md` 提供直接使用步骤，`app/README.md` 指向包内完整说明；`manifest.json` 逐一列出文件大小和 SHA-256。包内 `evidence/` 只包含本轮验收摘要与测试项目名称，不包含测试目录的虚构凭据、用户配置、历史聊天或原始系统日志。

程序与已验收输出的运行文件保持逐字节一致；仅打包副本中的 README 改为包内相对路径，完整原说明保留在 `docs/winui-preview.md`。ZIP 对应当前工作区快照，基准提交可追溯，但工作区尚未提交，因此本包不标记为来自干净发布提交，不提供正式更新安装器。

## 已验证与剩余范围

已完成本机 Windows 11 双屏 100%、指定测试文字复制回读及恢复、Explorer 实际目录、真实 Codex 空白独立资料生命周期、验证安装器安装/394 项窗口回归/卸载。共享核心 345 项和 WPF 309 项结果按相同程序集引用。详细限制见 [本机验收](windows-local-acceptance-2026-11-17.md)。

打包后从 ZIP 解压到含空格的新目录，逐文件核对清单与原验收运行文件，并运行实际解压程序的隔离任务流程检查。该检查用于验证重新打包和换目录没有损坏程序，不能代替另一台机器或不同系统环境。

本轮实际结果：ZIP 共 863 个文件，清单内 862 个文件逐一匹配，清单自身另与解压文件匹配；849 个应用文件（含 507 个手机后台文件）与已验收目录完全一致，仅根级应用 README 使用包内链接。实际解压程序的 17 项任务流程检查通过，程序集匹配本机已验收版本，ZIP 隐私扫描通过。包旁提供 `SHA256SUMS.txt` 和 `preview-verification.json`，不把原有 394 项完整界面回归表述为本打包阶段重新执行。
