# Codex Dock 0.10.1

修复 GitHub API 受限网络中的更新检查。

- API 返回 403/429 时，从同一仓库的 GitHub latest 发布页读取最新正式版本。
- 继续限定 GitHub 发布附件地址，使用 SHA-256 校验清单核验下载文件；安装前重新校验。
- 包含 0.10.0 的全部界面、连接名称备注、PAT / API Key、官方账号 + API、本机网关、托盘和开机启动功能。
- 源码与发布文件经过隐私扫描，排除真实 Krill Key、个人配置、认证、加密连接和备份。

在「应用设置与帮助 → 软件更新」中检查、下载并安装后续版本。首次使用请下载安装器，或退出旧版后解压便携包。完整功能与验证范围见 `release-0.10.0.md` 和 README。
