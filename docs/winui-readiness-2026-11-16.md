# Windows 首次配置与网关诊断迁移记录

本轮补齐 WinUI 的空目录配置引导、损坏读取修复流程和网关压缩/连接耗时展示。WPF 使用相同的加载状态与统计投影；默认交付入口仍保留 WPF，WinUI 继续作为独立预览。

## 行为

- 空目录不自动创建文件。工作台和连接页明确引导设置地址、密钥和模型，或在 Codex 完成同目录的官方登录后重读。没有连接时不能手动应用或自动接回，字段编辑与取消仍可使用。
- 已有官方文件登录、进程环境凭据、供应商认证与系统凭据设置继续保留；读取不执行认证命令，也不宣称在线连接已验证。首次保存先显示目标与脱敏差异，取消不创建目录，确认后沿用加密备份与事务保存，再等待单独应用。
- 配置、认证、加密数据或目录无法读取时，结束加载忙碌状态并清除旧快照、草稿标志与运行信息。界面展示文件类别与修复方向，禁用编辑和应用，保留重新读取、切换目录及查看恢复记录。修复后可在原窗口继续，不自动清空或重写损坏文件。
- 新的首次保存回归复现密钥延迟同步被邻近字段回填覆盖的问题。主连接与手机密码框现使用 WinUI 同步 `PasswordChanging` 事件保留草稿；未改动密钥格式、保存校验或加密文件格式。
- 两套窗口共用 `ModelGatewayDiagnostics`，只呈现计数、有效耗时、固定协议/传输/结束标签和 HTTP 状态。配置允许、客户端压缩触发、返回条目和确认成功分开显示，HTTP 200 本身不代表压缩成功；最近触发与最近成功各自记录协议、传输和时间。
- 统计同时显示排队/活跃数、队列、上游响应头、首数据、总耗时，以及无法完整检查的事件数。只覆盖当前模型网关进程，重启后清零；停止、未知监听者、读取失败和目录切换后清除旧统计。旧后台未提供的指标显示未知，不补成成功次数零。刷新仅访问本机已有认证健康入口，不启动服务或发送模型探测。

完整核心测试、最终 WPF 与交付 WinUI 的 Core/Application 程序集 SHA-256 逐一匹配；UI 报告绑定实际交付程序集，版本保持 `0.18.0`。手机后台 507 个文件与既有构建匹配，构建零警告、零错误，隐私排除扫描与 `git diff --check` 通过。校验和、最终截图和汇总分别位于 `preview-complete/SHA256SUMS.txt`、`preview-complete/screenshots` 和 `verification-summary.json`。

本轮没有改动用户的配置、运行中的旧预览或手机服务，没有执行真实更新安装器、写 Windows 启动项、发布新版本或修改安卓资源。需要让已经运行的模型后台使用本轮关闭修复时，可在新预览中明确重启模型网关；刷新不会自动重启。系统文件选择器的人工操作、实际 Windows 登录、真实执行端版本差异、其他 DPI、多显示器、Windows 10 和手机扫码仍需环境验收。

初次编译的测试空值标注、错误过滤缺少 `InvalidDataException` 和误把注释变更当作网关摘要变化，均已在专项阶段修正。随后实际界面首次保存复现密码事件回填问题，改用同步事件后完整 WinUI 293 项通过。最终并发复核又补上网关操作开始/结束时使旧读取失效的保护，避免停止后的旧结果晚到并回填。

完整回归还复现既有 WebSocket 路由退休用例的 TCP 重置：旧响应已转发完成，发送关闭帧后立即中止连接，可能让客户端来不及收到正常关闭。现先隔离旧路由，再给予最长两秒的关闭确认；迟到请求只等待关闭，不转发或重放到旧路由。原用例加强正常关闭与确认断言，新增“空闲旧路由拒绝迟到请求”的实际网关用例。关闭专项、普通分段 WebSocket 专项及最终 331 项完整回归通过，早期 `329/330` 失败日志保留，不作为最终交付证据。

## 使用与剩余覆盖

运行 `artifacts/winui-readiness-2026-11-16/preview-complete/app/CodexDock.WinUI.exe`，保留整个 `app` 目录。已有预览为单实例，先从托盘明确退出旧预览，再打开本轮文件。

后续继续核对 WPF 的只读当前配置/认证/环境摘要、集中帮助与目录便利入口，再进行系统和设备验收。两套窗口共享主要编辑与运行服务，并不等于原生设备验收或默认入口切换已完成；安卓视觉优化仍在 Windows 之后处理。
