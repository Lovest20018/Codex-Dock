# 0.16.1 网关生命周期修复审查

基于 0.16.0 发布提交 `898bb537313530515ee70ee87f0fd30b14ad4aad`，修复更新遗漏手机后台，并增加独立重启与停止后退出入口。

## 验证范围

- Release 构建 0 警告、0 错误；核心完整回归 95/95，包含真实模型和手机后台的进程替换、已保存配置逐字节保持，以及延迟退出进程的等待。
- WPF 开发程序回归 123/123，通过实际页面、托盘和关闭流程操作，检查隐藏窗口的草稿保留、两个网关停止、更新安装器启动时机和普通退出后的后台保留。无本机原生 Codex 的构建环境不运行 1 项可选来源读取用例，具体安装包检查次数以报告为准。
- Windows PowerShell 5.1 实际执行安装器辅助程序，正常停止目标安装目录中的冻结手机 worker，保留另一个安装目录中的 worker，不改写加密设置。
- 安装包验证在隔离目录中启动两个真实手机后台，覆盖安装其中一个副本，核对旧进程退出、其他安装目录不受影响、设置保持、安装内容逐文件一致、安装后界面及卸载行为。

安装包必须来自干净提交，包含源码、SHA-256 与安装验证报告。未安装到用户当前使用的目录，也未停止用户正在使用的网关；测试均使用工作区内的副本、虚构凭据及独立数据目录。没有调用真实模型或执行真实聊天任务。

发布流水线回归 8/8，要求实际运行中的手机网关升级、不同安装目录隔离和设置保持证据完整；缺失任一项会拒绝发布。

## 兼容边界

重启会短暂断开连接，应等任务结束后操作。独立重启读取保存值，不会应用表单草稿。“保存并启动”仍会先保存手机设置再重启。

应用内更新停止当前配置目录的两个网关。安装器的旧版兼容处理仅停止目标安装目录的手机后台，需本机认证、实例身份和监听端口所属进程一致；无法核对或未按时退出会阻止安装，由用户处理后重试。普通退出继续保留网关；卸载前应先停止网关。
