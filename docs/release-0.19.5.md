# Codex Dock for Windows 0.19.5 本地体验版

- 已配置的用户可从首页直接打开或回到 Codex。换默认模型仍在首页完成。
- 首次连接可打开原生 Codex 登录 ChatGPT，或在连接页填服务地址和密钥、读取并选择模型。核对目标后可保存并打开 Codex，正在运行时也可先仅保存。
- “高级工具”可搜索配置、网关、配置来源与备份。全部配置增加“常用”筛选，并标明资料核对版本。
- Dock 启动的 Codex 进程会合并回环代理排除项。配置来源可自动查找当前注册的商店版内核。

运行安装器并选择原安装目录覆盖。如果 Dock 提示有未保存的修改，先在提示中处理。安装后从原快捷方式打开。[验收范围](review-0.19.5.md)

需要回退时，可从托盘选择“停止网关并退出”，再覆盖安装 0.19.4。如需恢复设置，先在“高级工具 → 备份与恢复”核对备份内容。
