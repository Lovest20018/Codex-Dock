# Web / 安卓与上游功能对照

核对日期：2026-10-31。Dock 候选版本：0.13.3；上游基线：Codex Mobile Bridge **2.1.7 / Android build 40**，固定提交 `0721aa7dafa6177751ba7e568e0ad0efee05655b`。在线主页仍标注 2.1.7；本清单以固定提交源码为准，不将未核对的后续 main 改动算作已支持。

## 当前实际能力

Dock 是“在手机继续 Windows 本机 Codex App 已有聊天”的精简网关。安卓使用作者原 APK，未制作 Dock 专用 APK；聊天页从 Dock 加载，与浏览器使用同一套网页和 API。因此更新 APK 本身不会补齐聊天和服务端缺失。

已保留：列表、搜索、每批 100 条列表分页、最近文字历史、活动状态、原 owner 上的文字发送/执行中补充/停止、部分原生审批与同步文字提问、按聊天保存草稿、操作 UUID 和结果未知时禁止自动重放、密码登录、一次性扫码、安卓长期授权恢复、电脑端撤销设备和解除新登录限制。

## Web 与安卓共用功能的缺失

下表“Dock”同时适用于浏览器和原上游 APK 连接 Dock 后的聊天页。

| 功能 | 上游 2.1.7 | Dock 实际状态 |
| --- | --- | --- |
| 新建聊天/项目/分支 | 支持执行端允许的新建与项目目录选择 | 缺失，只能继续已有 App 聊天 |
| 会话整理 | 统一菜单、重命名、置顶、受支持会话归档、项目/分区移动 | 只有搜索、顺序列表和分页，无分类及整理写操作 |
| 模型和执行设置 | 模型、推理强度、Skill、普通/计划模式、权限和部分 Goal | 无手机修改入口；发送沿用电脑原会话设置 |
| 消息管理 | 未发消息编辑、排序、撤回，回复引用与分支 | 只有一个草稿及未确认操作保护；无队列、排序、引用、分支或历史编辑 |
| 富文本阅读 | Markdown、代码高亮/复制、公式、Mermaid、审查卡及文件位置链接 | 纯文字和执行详情折叠，没有上述渲染与交互 |
| 图片/附件 | 历史图片、工具截图、上传、附件发送、文件引用和下载 | 缺失，发送体只允许文字，没有附件和文件 API |
| 文件工作台 | 目录浏览、源码/PDF/HTML 预览、分屏、Git、终端等 | 缺失 |
| 长历史及同步 | 最近内容优先、按需上翻及增量恢复 | 无上翻旧历史接口；离线读取最多最近 12 轮，输出规范化至最近 120 项；前台约 2 秒、后台约 10 秒轮询 |
| 审批和提问 | 更多原生请求、计划实施、表单、异步提问等 | 仅命令/文件的本次批准、拒绝、取消，单轮权限批准/拒绝，同步 requestUserInput 文字回答；会话级批准、计划实施、MCP 表单、异步提问卡、身份验证等需回电脑 |
| CLI / WSL / SSH | 对应环境会话发现与显式继续，部分环境可创建 | 缺失，仅 Windows 本机 Desktop 来源；未接原 owner 的历史只读 |
| 账号/接入/额度 | 手机/Web 查看及切换保存的账号、模型、额度，管理客户端接入 | 缺失；桌面 Dock 的配置能力不等于手机具备这些能力 |
| 多 AI 客户端 | Codex、Claude Code/Cowork、DeepSeek Harness | 仅 Codex |
| 通知 | 收件箱、未读数、任务完成/请求提醒、安卓后台接收及第三方通知 | 缺失，认证接口声明 notifications:false，无事件/推送 API |
| 显示设置 | 语言、字号、主题、截图显示等 | 中文、随系统浅深色，没有上游设置面板 |
| 网络/网关管理 | 固定/临时入口、隧道、诊断、可选网络变化恢复 | 仅单一 HTTPS 根入口接已有反代，无隧道/证书/动态地址恢复及手机网关管理 |

复用的模型规范化代码仍将部分表单/计划/异步提问标为 supported；实际 Web 分支和 service 提交未实现，应按“需电脑处理”计为缺失。上游也有原生执行端、归档及 WSL 实验性限制，不能理解为上游在所有环境无条件支持全部操作。

## 安卓原生壳仍有的能力与不可用入口

| 原生能力/菜单 | 连接 Dock 后 |
| --- | --- |
| 摄像头扫码、手工 HTTPS 地址、保存多台电脑 | APK 自身仍有；密码/配对和页面事件已对接。多台电脑是多个分别运行 Dock 的地址，不是一个网关管理多个 SSH 主机 |
| 加密绑定、Cookie 恢复、退出/移除电脑 | 协议已对接，撤销后不能恢复；共享来源失败登录不会再撤销有效授权 |
| 返回聊天列表/电脑列表、刷新 | 导航及页面钩子保留，浏览器用真实上游注入脚本验证 |
| 手机设置、主题、权限、电池设置 | APK 自身仍有；主题仅覆盖其原生设置，不能补齐网页设置 |
| 账号与接入 | 菜单仍有，Dock 仅提示到电脑管理 |
| 通知收件箱、角标、后台任务通知 | 原生入口仍有，Dock 没有事件、任务推送、FCM 注册和通知跳转支持；开启接收可能显示重试/错误；本机十秒测试不证明任务通知可用 |
| 文件选择和下载器 | 原生代码仍有，Dock 无相应网页入口及资源 |
| APK 直接检查/下载/安装更新 | APK 的 GitHub 更新逻辑仍在，取决于手机网络与原签名；本轮未真机验证 |
| 电脑协助下载 APK 更新 | 缺失，无 /api/mobile/update/*；APK 会提示网关不支持协助更新 |

## P1 修复及升级影响

旧版输错五次会删除同来源的有效授权，并拒绝已有 Cookie。0.13.3 将自动新登录限制与显式 IP 策略分开：新的密码登录/配对仍被限制，有效 Cookie 保持可用，跨重启及解除限制不变。手动撤销、IP 黑白名单、过期和认证配置变化仍按原规则生效。

旧版已经删除的授权不能恢复，需重新登录或扫码。升级前先停止旧手机 worker 并退出 Dock，再安装和启动新版。仅退出编辑器不会停止后台。持久化格式和协议兼容，本轮不更改真实网关或设备授权。
