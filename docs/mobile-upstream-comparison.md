# Web / 安卓与上游功能对照

Dock 0.14.0，核对日期 2026-10-31。上游固定为 Codex Mobile Bridge **2.1.7 / Android build 40**，提交 `0721aa7dafa6177751ba7e568e0ad0efee05655b`。本轮按用户范围补齐 **Codex** 工作台，直接复用完整 Web 与后台模块。原 APK 从 Dock 加载网页，浏览器与安卓共享功能。

| 能力 | 0.14.0 实现 |
| --- | --- |
| 新建聊天、项目、分支和整理 | 原上游项目选择、信任确认、新建、重命名、置顶、归档、项目分区管理；受执行端原有条件限制 |
| 模型与执行设置 | 模型目录、推理强度、Skill、普通/计划模式、权限、Goal；按当前会话与执行端能力显示 |
| 发送和消息管理 | 原生 owner 提交、队列编辑/排序/撤回、引用、分支、已保存回执恢复；结果未知不自动重发 |
| 阅读与历史 | Markdown、代码高亮/复制、公式、Mermaid、审查卡、历史分页、增量同步和 SSE |
| 图片和附件 | 原生历史图片、工具截图、上传、引用、预览、下载与附件发送 |
| 文件工作台 | 工作区目录、源码/PDF/HTML 预览、分屏、Git 和原生终端；权限与路径边界沿用上游 |
| 审批与提问 | 上游命令/文件/权限审批、计划实施、表单、同步及异步提问；执行端未提供的类型仍需电脑处理 |
| 执行端 | Codex App、CLI、已登记的 WSL / SSH；发现与阅读不自动激活，创建/继续/重连为显式操作 |
| 账号与接入 | 手机查看/切换已保存接入、模型与额度；电脑点“管理 Codex 接入”复用上游登记、官方登录及 CLI / WSL 面板 |
| 通知 | 收件箱、未读、任务/审批提醒、安卓注册与接收、第三方通知；需用户配置渠道及手机权限 |
| 安卓协助更新 | 复用 `/api/mobile/update/*` 服务、版本检查与下载；仍由原 APK 验证签名及安装 |
| 显示与原生壳 | 原上游语言、主题、字号、图片设置、返回导航、登录恢复、文件选择和下载协议 |
| 网络入口 | 保留 Dock 单一已有 HTTPS 域名、群晖反代、路由映射及本机控制。证书、FRP、Cloudflare/Tailscale 等部署仍由现有外部服务管理 |
| 其他 AI | 按本轮范围关闭 Claude Code/Cowork、DeepSeek Harness；不显示或启用这些接入 |

“复用”指保留固定版本代码及 API，并非保证所有 Codex 版本、WSL 发行版、SSH 主机或代理环境无条件支持。Windows 终端随包提供锁定 ConPTY；SSH 仍需系统 `ssh`、已配置的主机与上游要求的远端 Python。账号操作可能按原上游流程重启 Codex，界面继续显示确认提示。

升级继续保留 0.13.3 的共享来源授权修复。worker 协议升级为 4，原设置 1/2/3 可读取；原设备 Cookie 与身份保留，旧操作账本迁移但不重放，浏览器旧草稿需确认当前账号后复制。停止旧 worker 后再更新。
