# Android 0.2.0 验收记录

本轮优化安卓原生导航与随 APK 注入的聊天呈现层。固定上游快照和七项既有 Web 覆盖保持原有散列，Windows 版本和网关 API 不变。沿用 0.1.1 的包名、签名和 Logo。

## 自动验证

- 35 项 Android 14 隔离模拟器检查通过：真实生产 WebView 登录、原生桥令牌拒绝、外链限制、三项导航保留页面、主题、配置变化、文件选择取消、过期文件回调拒绝、鉴权下载、通知服务和本机通知。
- 使用生产输入处理器及草稿存储验证文字草稿、账号隔离、未验证账号保护、附件检测、阅读位置保存、详情导航显隐、返回列表、Activity 重启后的聊天定位和新 WebView 中的草稿持久化。
- 横屏和 320dp WebView 加 130% 文字缩放没有文档横向溢出。布局截图经过检查；这些检查不覆盖所有屏幕、字体和厂商键盘。
- 在独立模拟器先安装 0.1.1，写入测试电脑、主题和标记，再覆盖安装 0.2.0，核对设置保留。
- 共享移动 Web 脚本 62 项 Node 测试通过。生产 APK 不带测试钩子或调试标记；检查签名和 APK 对齐。

## 测试边界

网关使用生产 Python/Web 代码及临时数据，执行端指向不存在的原生程序，未发送真实模型任务。输入、导航和阅读测试使用隔离的示例聊天作用域；无真实账号或个人聊天。网关代理仅为模拟器回环 HTTP 映射 Host/Origin 和 Secure Cookie，不代表公网 HTTPS 验收。

仍需真机验收：相机扫码、公网域名与证书、厂商键盘与省电策略、真实 Codex/SSH/WSL 任务及长时间后台通知。发布包附输入散列 manifest、源码包和 SHA-256 清单。
