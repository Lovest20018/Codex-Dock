# Windows 0.16.3 配置确认流程审查

本版包含配置确认界面、模板预览撤回、默认值文案和嵌套 TOML 写入修复。Android 原生代码、版本及签名保持不变。

## 保存边界

- 确认页列出本次所有文件、用户环境变量与修改明细，普通值通过已有安全显示逻辑呈现；认证、加密连接和备注只显示内容已隐藏。
- 确认使用预览时固定的保存计划，主界面在确认时不可编辑；重新读取过配置则要求重新确认。实际写入沿用原有锁、外部修改检测、加密备份与事务回滚。
- 模板预览是临时草稿。返回只撤回该次预览，不会清除原有草稿；修改勾选后重新进入确认，不会残留此前取消的字段。
- 只读预览没有写入按钮。错误格式不能确认，保存失败保留草稿，切换预览标签不能绕过失败状态。成功必须完成写入和重新读取，才显示完成结果。
- 方案库与 config.toml 独立保存，升级不读取或打包用户本地的模板、配置、凭据与备份。

## 嵌套配置

新增字段优先写入最近的现有表或内联表，使用相对字段路径，避免根部 dotted key 重新定义已有 `[features]`。覆盖普通表、带引号表名、内联表、已有子表、dotted key、CRLF 与非表父值拒绝；保留其他字段、注释与已有 V2 开关。父值为布尔值时仍要求用户明确改为表，不擅自切换代理模式。

## 验证

核心回归 93 项通过，包含嵌套字段写入的复现及保留性检查；发布脚本回归 13 项通过。最终实际 WPF EXE 隔离检查 135 项通过，覆盖手动确认、返回调整、模板改选、恢复默认、脱敏、无效输入、备份、外部编辑冲突、最小窗口及深色主题，并验证写入后读取结果与确认计划一致。

正式发布继续要求重新冻结手机后台、自包含 WPF 打包、发布程序完整界面回归，以及隔离安装器的运行中手机后台覆盖升级、其他安装目录隔离、逐文件比较、安装后界面与卸载检查。实际结果及程序哈希在安装验证报告、包内 UI 报告和 release manifest 中记录。

检查使用合成凭据和隔离配置目录，不修改用户当前 config.toml，不部署到用户安装目录，不启动真实模型任务。实体手机、公网服务、真实 Codex / WSL / SSH 任务不在本版新增验证范围。
