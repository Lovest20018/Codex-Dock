# Codex Dock 0.19.6

## Windows

- **手机连接**在同一页填写入口和登录信息，保存、启动服务并准备配对码。服务已运行时，直接选择 **生成配对码**。HTTPS 检测失败时可以在同一页重试，或复制转发说明给网络管理员。
- **扫码和聊天接入分别显示**。手机配对后，可以在 **选择允许手机访问的 Codex** 中启用可用接入。
- **模型网关诊断**在 **高级工具 → 模型网关 → 本机模型网关 → 压缩与连接耗时** 查看。复制连接诊断时，会带上时间、传输阶段、上游请求 ID，以及网关确实收到的最终响应 ID。

## 手机与 Web

- 聊天中的交互图表可全屏打开。重新进入聊天时恢复图表已保存的状态，图表提出的追问可以先放入草稿。
- 在输入框键入 **/** 可以打开现有的模型、权限、Skill 或会话操作。聊天名称可以留空。原生桌面聊天按 Codex 的命名逻辑处理，当前 CLI 和 WSL 共享运行时使用默认名称来保存空聊天。
- 消息有原生时钟时显示时间。会话菜单可以查看当前聊天的附属聊天，关闭列表只离开视图。展开命令或 MCP 工具条目时，网关按原会话、回合和条目标识读取保存的延迟输出。
- Lovest Code 0.2.6 支持在连接探测时返回电脑列表，并允许重新选择离线的电脑。安装新版 Windows 手机网关与 Lovest Code 0.2.6 可使用安卓图表预览。

使用 Windows 安装器选择现有目录，可覆盖安装。安卓用同一包名和签名的 APK 覆盖升级即可保留设备授权及本机设置。安装后从 Windows Dock 启动手机服务，再按连接页提示准备配对。
