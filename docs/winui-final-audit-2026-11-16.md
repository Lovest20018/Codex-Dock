# Windows 迁移收尾核对

本轮逐项对照 WPF 的导航、动态工具与窗口入口，补齐 WinUI 的键盘操作、窗口按钮和窄窗口动作布局。正式交付入口仍为 WPF；本记录区分功能回归与原生环境验收。

## 对照结果

| 旧版功能或入口 | WinUI 对应位置 | 结果与边界 |
| --- | --- | --- |
| 概览与统一应用 | 工作台、固定应用区 | 已有目标选择、确认、取消、重试及强制退出保护 |
| 服务、API Key、官方登录、旧 PAT | 连接配置 | 共用保存、登录读取和模型发现服务，确认后写入 |
| 默认模型、行为、能力目录、专用审核 | 模型与行为 | 使用同一配置草稿与 Core 校验 |
| 全字段、高级项、动态名称、字段说明 | 全部配置 | 分页和错误输入保留，敏感字段不进入明文摘要 |
| 配置来源与聊天参数 | 配置来源、聊天参数 | 明确选择执行端或记录；读取可取消，范围单独说明 |
| 独立 Profile | Profile 文件 | 草稿与保存独立；主配置与当前聊天不切换 |
| 模板管理与加入草稿 | 方案库 | 编辑库与保存主配置分开，沿用冲突与撤销保护 |
| 加密备份与中断恢复 | 备份与恢复 | 先核对差异，一次确认一次提交 |
| 客户端增强、自动接回、快捷方式 | 客户端增强 | 共用运行持有者与操作租约 |
| 模型和手机网关、自动启动、统计 | 网关管理 | 从已保存设置分别操作，统计只属于当前进程 |
| 手机入口、扫码、设备与接入管理 | 手机连接 | 页面草稿独立，实际公网与设备仍需实机验收 |
| 正式版更新与 Windows 启动项 | 软件更新、Windows 设置 | 固定来源与安装校验；启动项绑定程序和目录 |
| 当前文件、帮助、配置位置 | 文件预览、使用说明、当前工作区 | 脱敏快照与未保存草稿范围分别说明 |
| Ctrl+S / Ctrl+F | 当前页面保存、当前筛选或全部配置 | 本轮补齐，调用对应已有入口 |
| 最小化、收起、退出 | Windows 设置中的“窗口与后台” | 本轮补齐；退出沿用草稿与增强保护 |
| 最小尺寸与窄窗口按钮 | 窗口边框、动作组 | 本轮补齐，按当前显示器 DPI 与工作区限制尺寸 |

本次入口核对未再发现需另建业务流程的缺口，尚未覆盖的环境项保留在下文。对照以当前仓库 WPF 和共享服务为准，不能代替每种系统及设备的现场验收。

## 本轮交互

`Ctrl+S` 使用当前页面可见的保存入口：Profile 页只核对 Profile，编辑方案时只保存本机方案库，手机页走保存并启动确认，其余页面按可见的主配置保存区核对。没有相应草稿、正在处理操作或已打开模态框时，不产生额外保存。主配置与 Profile 仍需原有差异确认；键盘不会自动应用或重启 Codex。

`Ctrl+F` 在帮助与配置来源页聚焦当前筛选框，其余页面进入全部配置并聚焦搜索；`F1` 或 `Ctrl+Shift+H` 打开帮助。验收机的 Snow Shot 全局快捷键截获了 F1，用户退出截图叠层后改用备用组合键完成帮助验证，没有修改系统快捷键设置。F1 的应用内处理有隔离回归，受全局热键占用时使用备用入口。

“窗口与后台”提供收起到托盘、最小化到任务栏和退出预览。托盘不可用时禁用收起，普通关闭和明确退出继续沿用已有保护。快捷键和按钮不新增进程操作分支。

原生尺寸适配器在窗口消息中按当前 DPI 计算最小跟踪尺寸，基准为 720×540 逻辑单位，并以当前显示器工作区限制上界。初始 1120×820 同样按 DPI 缩放并放入工作区。横向按钮改为测量后换行的动作面板，覆盖固定保存区及动态配置、方案命令。

本轮工件均位于 `artifacts/winui-final-audit-2026-11-16`。手机后台 507 个文件与既有构建逐一匹配，构建零警告、零错误，隐私扫描和 `git diff --check` 通过。最终汇总、校验和和截图分别在 `verification-summary.json`、`preview-final/SHA256SUMS.txt`、`preview-final/screenshots`。

专项逐页检查 17 个页面在 1120×820、900×760、720×540 下的动作区域和固定保存区，另以 460×420 的逻辑区域检查 Profile 动作实际换到多行并保留保存入口。这是布局压力测试，不能等同于改变真实显示器 DPI。另验证干净状态无写入、保存取消、Profile/方案/手机范围分开、模态与忙碌禁用、搜索焦点、帮助备用键、最小跟踪消息、最小化、托盘隐藏和退出取消。

原生键盘与目录选择器使用最终程序的专用隔离模式，配置位于工件目录，禁止选择该测试目录之外的文件夹。实际按键进入真实确认，取消后不产生配置写入或备份。系统 PickerHost 选择器能显示但未进入自动化可控窗口列表，取消与选择步骤由用户协助。最终 `native-retry/report.json` 的 5 项通过：实际保存、搜索与备用帮助键，以及选择器打开两次、取消一次、成功选择一次；报告核对返回的当前目录、草稿状态和前后文件，两个目录均无新增保存或备份。

早期原生验收在 F1 被截图工具截获、用户关闭窗口时未完成，保留为中断记录；首次完整自动回归窗口也提前关闭，没有生成最终报告，不计为通过。最终重新打开隔离窗口完成系统选择，关闭该测试窗口后再独立执行完整回归。构建脚本现为完整验收子进程清除专项筛选并恢复调用方环境，缺失最终报告或文件对应失败都不能标记通过。

提前关闭的 `ui-final` 留下一个隔离手机后台，最终检查通过该测试目录的 `MobileGatewayManager` 认证控制正常停止，未终止用户的安装版手机服务。最终完整回归自行完成后台清理；所有验收窗口已退出。

交付位置为 `artifacts/winui-final-audit-2026-11-16/preview-final/app/CodexDock.WinUI.exe`，保留整个 `app` 目录。原有预览为单实例，先从托盘明确退出原预览，再打开本轮入口。

当前机器未完成其他物理 DPI、多显示器切换、Windows 10、实际登录启动、真实安装器、真实 Codex 重启或公网手机设备验收。实际剪贴板与 Explorer 仍由隔离替身覆盖，不访问用户剪贴板或改动用户文件管理器。上述项目与默认入口切换继续分开记录。
