# Codex Dock 0.11.0

精简为 PAT 配置编辑器，并修复修改后无法保存的问题。

- 移除 ChatGPT 账号登录、官方账号混合模式和本地网关，默认打开 PAT 连接页。
- 服务地址、PAT / API Key 和默认模型集中在同一页，连接名称、备注及认证选项收进更多选项。
- 保存栏持续显示；手动输入模型即可启用保存，获取模型期间也能保存本地修改。
- 保存失败会在按钮附近显示原因并保留草稿；保存后从磁盘重新读取确认。
- 旧版混合连接可读取已保存的模型凭据，点击保存后备份并转换为直连。
- 保留普通配置、模板、加密备份、托盘、开机启动及 GitHub 更新。

更新前请从托盘退出旧版工具。保存新连接后，完全退出并重新打开 Codex。配置转换后使用所填写的 PAT / API Key。
