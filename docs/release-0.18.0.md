# Windows 0.18.0 · 模型、专用审核与统一应用流程

本版统一 API Key 连接、模型与审核设置，并修复保存和重启时把 Codex 自动更新误判成配置冲突的问题。

- 保存完成、概览、速度兼容和备份恢复共用一个应用面板，显示准备连接、退出旧实例、打开 Codex及加载兼容的进度。
- 保存、恢复、状态刷新和官方登录读取会保留当前计算机操作管道、注释及已核对身份的同账号新令牌。实际模型、速度、审核、路由或账号变化仍阻止覆盖，并保留草稿；新备份包含加密的前后快照，旧备份继续按摘要核对。
- 退出超时可先完成 Codex 的退出确认，再重试；也可单独确认结束已核对的实例。兼容加载失败会显示 Codex 是否已经打开，可只重试速度兼容。
- “模型与行为”集中显示模型、推理、速度与自动审核，可固定 `codex-auto-review`。能力目录同步保留审核映射、原有速度及推理元数据，目录与配置一起预览、备份和恢复；专用审核失败保持阻止执行。
- API Key 直连无需 ChatGPT 登录或本机模型网关。旧 PAT 可读取并显式迁移，迁移前展示差异并加密备份。可选的“官方账号 + 独立模型入口”保留原生登录；应用到 Codex 前自动检查并启动本机模型网关。
- 两个网关在“网关管理”独立启停，自动启动默认关闭。概览区分文件保存、桌面实例和聊天实际参数；聊天诊断仅读取选定记录的白名单元数据。
- 可选的 Fast / Ultrafast 桌面兼容按配置目录隔离、默认关闭。开启后从统一面板应用，并保持 Dock 运行；模型目录和服务仍决定可用档位。安装更新不会自动开启兼容或迁移认证。

## 升级与回退

使用安装器覆盖升级，或将便携包完整解压到独立目录运行，无需安装 .NET。更新前完成当前任务，并从 Dock 选择“停止网关并退出”；应用内更新会等待所管理的后台退出。安装器保留用户的 Codex 配置、手机设置及未由安装器创建的文件。

更新 Dock 后，通过应用面板打开或重启 Codex，再新建聊天核对。进程打开成功不代表旧聊天已加载新参数；项目、Profile 与组织配置仍可覆盖默认设置。回退配置使用“备份恢复”，回退程序使用上一版安装器，两者分别处理。

本版仅更新 Windows；Android 保持 [0.2.4](https://github.com/Lovest20018/Codex-Dock/releases/tag/android-v0.2.4)。附件包括安装器、便携包、对应提交源码、SHA-256、安装验证报告和发布清单。
