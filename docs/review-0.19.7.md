# Codex Dock 0.19.7 验收

本机验证已在正式版运行时打开独立预览，并通过 498 项 WinUI 检查、83 项手机网关测试、22 项 Web 测试和 14 项发布脚本测试。

| 项目 | 检查 |
| --- | --- |
| 独立预览 | 以无参数启动开发预览，核对它创建自己的「Codex Dock · 界面预览」窗口。临时演示目录与实际配置目录分开。 |
| 首页和连接页 | 1120 × 820 DIP 浅色与 720 × 540 DIP 深色窗口覆盖页头、摘要、首屏输入和固定核对操作。另在 460 DIP 逻辑宽度核对长文本换行和目录菜单。 |
| 高级工具 | 1840 × 900 DIP 宽窗口及压缩视口核对三列、两列和单列。检查十个入口、Ctrl+F、搜索别名、结果触发、原始字段跳转与缩放焦点。 |
| 正式安装包 | 检查 WinUI 3 程序、主题 XBF、运行时和冻结的手机后台。安装验收覆盖运行中的 Dock 与网关、同目录升级、其他安装目录隔离、逐文件摘要和卸载保留用户文件。 |
| 发布附件 | GitHub Actions 按版本和提交核对安装器、便携包、源码和校验文件，复核上传附件摘要后公开。 |

窗口实测采用 100% 缩放。其他物理 DPI、系统高对比度、屏幕阅读器、实际登录和手机公网环境需要现场验收。前序手机后台与桌面兼容性的范围见 [0.19.6 验收](review-0.19.6.md)。
