# Windows 全部配置、方案库与恢复迁移记录

本轮为 WinUI 开发预览加入全部配置、方案库和备份恢复三个页面，保留 WPF 作为默认交付入口。安卓应用、手机后台源代码和真实用户的运行服务未在本轮修改。

## 最终行为

- 全部配置按已配置、全部和已修改范围查询同一份内存草稿，支持搜索、分类、每页 20 行、高级项与带引号的动态名称。字段采用已有 schema 校验，错误输入保留并阻止保存；翻页和导航不丢失输入。敏感值保持掩码，父子路径冲突以可恢复错误显示。字段、模型与连接通过同一确认和加密保存流程提交。
- 方案库提供新建、编辑、复制、删除、恢复内置方案和捕获当前普通设置。方案差异默认保护已有草稿；加入方案只修改配置草稿，撤销时保留后续手动编辑。方案编辑有独立的固定保存区，离开工作区或退出前处理未保存选择。WPF 与 WinUI 共用 `TemplateLibraryService`，库文件写锁内核对读取摘要，拒绝旧窗口覆盖新改动。
- 备份恢复先展示具体差异、备份时间、来源和写入目标。取消无写入；确认消费一次恢复计划，并在写锁内复核来源与快照。正常恢复备份恢复前状态，中断事务使用原记录恢复并归档。保留可证明的同账号令牌刷新、合法运行管道轮换和注释；模型目录仍按 Core 原有保护规则恢复。未完成保存会禁用配置编辑和桌面应用，恢复后解锁。
- 配置命令只作为文本保存，编辑和恢复不会执行 MCP 命令、启动真实网关或重启用户 Codex。配置来源与独立 Profile 工具、Windows 开机启动注册等入口仍待迁移。
