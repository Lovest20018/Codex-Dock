# Codex Dock for Windows 0.19.0

新版 WinUI 3 成为 Windows 默认界面。安装器沿用原安装目录、应用身份和 `CodexDock.exe` 入口，可直接覆盖旧版。

- 按工作台、Codex 配置、运行与增强、手机访问、诊断与恢复组织功能；目录切换、待处理草稿、当前对象保存和帮助入口集中显示。
- 配置、Profile、方案与手机服务分别保存，继续通过差异确认、加密备份和外部变更检查。保存与应用到 Codex 保持两步。
- 增加可选的旧聊天接续、增强快捷方式与自动接回，保留活动任务和未知写入保护。
- 混合连接可设置 60–3600 秒的 HTTP 响应头等待，默认 120 秒；普通模型目录保留经校验的能力声明，修复推理说明缺失导致目录无法读取的问题。
- 配置来源页可读取独立执行端的实验功能阶段和观察值，将支持的修改暂存为主配置草稿；不把该快照冒充现有聊天状态。
- 手机网关适配 v13 同步与兼容结构，改善断线恢复、模型缓存及列表容错；修复服务启停后的配对状态同步与恢复配置后的来源刷新。
- 更新应用、窗口、托盘、Web 页头、favicon 和添加到主屏幕图标为“接入 · 浅绿”，统一 Windows、Android 与 Web 标识；Web 图标使用新内容摘要更新缓存。

## 安装与升级

先在旧版 Dock 选择“停止网关并退出”，并退出此前的独立 WinUI 预览，再运行 `CodexDock-0.19.0-Setup-win-x64.exe`，选择原目录覆盖安装，无需先卸载。原快捷方式继续打开新版界面。

便携版完整解压后运行 `CodexDock.exe`，保留整个 `mobile` 文件夹与运行库。包内包含 .NET、ASP.NET Core、Windows App SDK 和 Python 手机后台；用户配置、认证及聊天不随包分发。

升级后启动手机服务并检测 HTTPS 入口。现有 Lovest Code 可继续连接；安卓图标更新单独发布为 [0.2.5](https://github.com/Lovest20018/Codex-Dock/releases/tag/android-v0.2.5)，可沿用原包名和签名覆盖升级。

如需回退，停止网关并退出后可覆盖安装旧版。旧版可能不提供新增功能；需要恢复配置时，使用保存前的加密备份并核对差异。

## 验证与边界

本版基于已完成的 364 项核心、425 项 WinUI、309 项 WPF、74 项手机后端及安卓模拟器 72+22 项检查；正式构建另执行实际 EXE、安装后窗口、同目录后台停止、其他安装目录隔离、文件摘要与卸载保留验证。最终报告随附件提供。

实体手机公网 HTTPS、不同厂商省电/键盘、Windows 10、其他物理 DPI 与真实模型任务不由隔离回归代替。模型能力仍以目录声明和实际服务为准，压缩兼容保持透明转发。

详细范围见 [本版审查](https://github.com/Lovest20018/Codex-Dock/blob/v0.19.0/docs/review-0.19.0.md)。
