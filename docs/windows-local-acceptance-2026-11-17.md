# Windows 本机剩余项验收

本轮按“继续完成剩余部分”推进本机可执行的环境验收。用户已确认复制专用测试文字，并明确其他 Windows 10、不同缩放和安卓设备稍后提供。本机已完成范围与缺少设备的范围分别记录。

## 当前环境

实际 Windows 构建为 `10.0.26300`，显示版本 26H2，属于 Windows 11。系统兼容注册表仍返回“Windows 10 Pro”，不能据此算作 Windows 10 验收。当前两台显示器均为 1920×1080、96 DPI / 100%；未改动系统显示设置。ADB 当前无已连接设备。

## 本机显示、目录与复制

最终预览在两台实际显示器间移动，核对窗口原生 DPI、XAML 比例、工作区、最小尺寸及连接/模型/Profile/设置/帮助动作区域，保留未保存草稿和原文件。computer-use 实际核对含空格与 `&` 的测试目录及两份虚构文件，并关闭本轮打开的 Explorer 窗口，未读取文件正文。

用户先手动复制 `CODEX_DOCK_CLIPBOARD_TEST_20261117`。只有受限 Unicode 文本与该标记完全匹配（允许末尾换行）时执行复制验收；否则跳过，后续用户复制优先。原生测试实际核对完整目录路径和脱敏认证摘要，最后恢复并回读同样的测试文本。最终本机专项 **12 项通过，进程退出码 0，`Restored=true`、`Superseded=false`**。普通复制继续使用 WinRT DataPackage，禁止历史和跨设备同步。

测试辅助路径不保存或回写任意 OLE/WinRT 数据对象。此前只接受单一 Text 格式时，被复制来源附带格式阻止；放宽后一次摘要复制检查失败，后续一次退出发生 XAML `0xc000027b`，均保留为失败记录。最终改为严格长度限制的原生 Unicode 读取，不保留数据对象，复制和恢复均从实际剪贴板回读确认，最终运行正常退出。

这证明本次经过明确授权的测试文本复制、回读和恢复通过；不代表支持保存并恢复图片、文件、富文本等任意剪贴板对象，也不代表已恢复 11 月 16 日事故前的内容。此前事故记录保留在 [本机显示与目录验收](winui-environment-2026-11-16.md)。产品本身不承担任意剪贴板备份恢复，测试不应再以此为验收前提。

本轮记录：`native-safe/report.json`、`native-safe/environment.json`、`native-safe/clipboard-result.json`。前面的 `native-current` / `native-final` 为跳过，`native-verified` 为复制失败，`native-complete` 虽生成部分报告但退出异常；这些不能替代最终成功记录。

## 真实 Codex 生命周期

使用当前已安装 Store Codex `26.1111.2228.0`，通过既有 Core 的商店别名、进程识别与重启实现进行验证。每次只创建新的临时 `CODEX_HOME` 和 Electron 资料目录，清除继承的密钥/令牌环境，不导入登录、不创建聊天、不发送模型请求。

验收共 **6 项通过**：独立实例实际打开、临时资料初始化且未导入账号、正常关闭到托盘时阻止重复启动、仅对空白测试实例明确确认重启、新实例仍属于同一临时资料目录、清理后原用户主进程身份保持不变。预先存在的用户主进程 ID 与创建时间均核对，没有对它发送关闭或结束请求。

当前 Codex 的关闭按钮会收起到托盘，单纯 WM_CLOSE 不能证明正常退出。因此“正常退出后重开”未伪装为通过：第一次测试保留失败，后一次明确验证“退出受阻 → 不重复启动 → 确认后只结束测试实例并重开”。清理也仅匹配本次空白资料目录。登录和真实任务状态下的增强接入不在此验收中。

新增命令 `CodexConfig.Tests.exe --installed-desktop-acceptance <新的 artifacts 子目录>` 为明确选择的手工验收入口，不加入自动完整测试。它拒绝现有目录，关闭或结束前同时核对进程身份和专用资料目录。`--cleanup-installed-desktop-acceptance` 仅清理该入口已创建的空白资料目录。

报告：`installed-desktop-verified/report.json`；失败历史为 `installed-desktop.log`。Core 文件与已验证基线一致。

## 实际安装器

本轮使用仓库现有 Inno 文件安装、后台停止与卸载规则生成本机验证安装器，使用独立 AppId、固定 artifacts 目标和强制 `VERIFYONLY=1`。此程序只用于验收，不是公开安装包，不能安装到正式程序目录，也不切换默认入口。

验证包括停止同一安装目录的旧测试手机后台、保留另一个安装目录的后台与全部测试手机设置、逐文件 SHA-256 核对、安装后从实际安装目录运行完整 WinUI 回归，以及卸载后保留用户哨兵文件。正式卸载注册、用户环境和 Dock 启动项前后比较，保持不变。安装器代码未新增面向生产的业务分支。

最终验证通过：实际安装目录运行的完整 WinUI **394 项通过**，850 个安装文件逐一哈希匹配，卸载保留用户哨兵文件，正式注册、环境和启动项未变。结果在 `installer/verification.json` 中记录，安装和卸载日志保留在同目录。不把验证安装器等同于签名发行包、正式发布或用户安装升级。
