# Windows 0.19.3 本地体验版验收

本批实现从 WinUI 工作台更换模型。打开选择窗口读取当前服务或本机目录。确认使用原有加密备份、文件冲突检查和桌面正常退出逻辑。所选实例、配置目录或增强选项发生变化时，先重新核对。

## 回归范围

- WinUI 专项使用隔离配置和模型数据验证新模型的选择与返回、一次确认保存并重启、仅保存与后续应用、退出受阻正常重试、审核资料缺失、目标变化、外部修改、离线目录和取消读取。专项随完整窗口测试执行。
- 安装验证检查实际包内程序集、覆盖安装、旧手机后台退出、同机其他实例隔离和卸载保留用户文件。安装与窗口记录由打包脚本生成。
- 原生窗口控制使用独立 Windows 夹具。真实服务上的模型是否可用、真实任务退出确认和实际聊天采用的模型，需在使用环境核对。应用结果区分本地已保存、窗口已重新打开和新聊天核对。
