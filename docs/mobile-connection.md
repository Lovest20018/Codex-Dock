# 手机连接

通过自己的 HTTPS 根域名，在上游 Codex Mobile Bridge 安卓 App 或浏览器中继续 Windows 本机 Codex App 的已有聊天。安装包已附带手机后台及 Python 运行时，无须安装 Python。0.13.2 起无需填写代理来源 IP。

## 电脑设置

1. 保持电脑、Codex App 和需要继续的聊天打开。
2. 在 Dock 左侧进入 **手机连接**，填写已有的 HTTPS 根域名，不带路径或查询参数。允许非默认 HTTPS 端口，例如 `https://codex.example.com:888`。
3. **本机监听端口** 默认 `13090`，可手动修改，范围 `1024–65535`。更改后点击 **保存并启动**，并同步修改反向代理目标。端口被占用时会报错，不会自动换用其他端口。
   服务接受本机代理、群晖等其他设备的反向代理和路由端口映射，无需配置来源 IP。私有管理端口保持仅本机。
4. 设置独立手机账号及 12–256 字符密码。此处使用手机访问密码；再次保存时密码留空会保留原值。
5. 点击 **保存并启动**，配置反向代理后点击 **检测 HTTPS 入口**。程序核对证书和实际 worker 实例，不接受跳转。
6. 检测通过后生成二维码，用上游安卓 App 扫码添加电脑；也可在安卓 App 手动输入 HTTPS 域名，再使用上述账号密码登录。

手机设置单独保存，立即生效。Codex 配置页底部的 **保存配置** 与此设置独立。

## 反向代理

如果群晖通过**公司公网 IP**转发到电脑，在路由器将 HTTP 端口映射到 Windows 电脑即可。Dock 无需填写公司或家里的公网来源 IP。旧设置中的代理 IP 在升级后不再限制连接。

端口可以分别使用：外部 HTTPS/FRP 入口 `888`，群晖目标为 `http://公司公网IP:13090`，公司侧转发到 Windows 的 `13090`。保持 Host 为外部域名及 `:888`。此链路中的公司公网端口转发必须能到达电脑，群晖的 frpc 本身不会自动开放公司侧网络。

手机 HTTP 端口监听所有 IPv4 接口。本机代理可转到 `http://127.0.0.1:13090`；群晖等设备填写电脑可达的局域网 IP 或公司公网 IP。Windows 防火墙如有拦截，需放行该端口。程序不自动修改路由器或防火墙。

`127.0.0.1` 指向使用该地址的设备自身。在群晖上填写它，目标就是群晖；除非群晖该端口已有通向电脑的通道，否则不能到达电脑。电脑和代理在不同网段时，还须存在可达的路由、VPN 或 FRP；只改变监听范围无法建立网络通道。

- 将整个 HTTPS 根站点转给手机 worker，包括 `/`、静态资源和 `/api/`；不支持路径前缀部署。
- 保留原始 `Host`，包含外部非默认端口；例如外部 `:888` 不能被替换为 `127.0.0.1:13090`，也不能丢掉 `:888`。
- 保留浏览器 `Origin`、Cookie、`X-CSRF-Token` 与安卓 `User-Agent`。远端代理的 `X-Forwarded-For` 不作为可信身份；登录限速和设备 IP 使用电脑实际收到的连接来源。因此设备列表可能显示代理或 NAT 地址，同一代理的多次错误登录共享新登录限制。0.13.3 起自动限制不会撤销已有设备授权，可在 Dock 解除登录限制。
- 使用有效且受手机信任的 TLS 证书。不要将 HTTPS 跳转到另一域名，也不要缓存 API 或网页内容。
- 发送操作可能等待原 Codex owner 响应，代理读取超时应大于 90 秒。网页通过轮询同步，无需公开 WebSocket 路由。
- 私有管理端口由程序单独选择，只供本机 Dock 控制；不要转发到公网。

502 表示入口未能连接到后台；检查服务运行状态、代理目标、端口映射和防火墙。403 表示已收到请求但 Host、Origin 或登录验证不匹配；核对完整外部 Host（含端口）和 Origin 转发。入口检测会区分这两类错误。

直接打开 `http://127.0.0.1:13090/` 会显示本机诊断页，并提供配置的 HTTPS 入口。该 HTTP 地址不提供登录和聊天 API。

## 支持范围

| 支持 | 当前边界 |
| --- | --- |
| 列表、搜索、历史和活动状态 | 只读取当前配置目录中的本机 Codex App 聊天；手机显示最近的文字记录 |
| 发送、补充和停止 | 必须由打开该聊天的原桌面 owner 接收，沿用原模型、工作目录和权限 |
| 审批和原生提问 | 支持本次命令/文件批准、拒绝、取消，单轮权限批准及文字回答；其他类型回电脑处理 |
| 登录、扫码、撤销 | 扫码有效期 5 分钟、单次使用；安卓设备授权支持后台重启后恢复并可撤销 |
| 断连处理 | 操作结果未知时保留草稿和回执，禁止自动重放；先核对电脑结果 |

不提供新建任务、独立 CLI、WSL/SSH、终端、任意 RPC、上传下载、账号池、其他 AI 客户端、隧道及证书管理。上游安卓 APK 的原生附加菜单仍属于该 APK，服务不会为其提供额外功能。

Web 与安卓聊天页共用此网关实现，完整缺失清单见 [与上游功能对照](mobile-upstream-comparison.md)。安卓原生通知、账号和协助更新菜单不代表对应服务已实现。

## 启停、数据和升级

关闭 Dock 后手机服务继续运行；在 **手机连接** 可以显式停止。重新登录 Windows 后需要打开 Dock 并启动手机服务。开启 Dock 的开机启动只会启动编辑器，不自动开启手机端口。

每个 Codex 配置目录独立保存手机设置与设备记录，位于 `%LOCALAPPDATA%\CodexConfig\mobile\<目录标识>`。设置使用当前 Windows 用户 DPAPI 加密，设备记录仅持久化令牌摘要。更改密码、账号或域名后需要重新登录；撤销设备后，其保存的 Cookie 也不能恢复授权。

升级前先在手机连接页停止服务，再从托盘退出旧 Dock。升级后打开 Dock，在手机连接页启动并检测入口。便携版本必须完整解压，保留主程序旁的整个 `mobile` 目录。恢复旧版时先停止新手机服务，再安装原版本；0.12.x 不管理手机服务。升级和回退均不要求覆盖个人 Codex 配置或手机数据。
