# Android 0.2.1 验收记录

根据手机截图调整安卓列表、聊天标题、输入区和模型面板。修改范围为 APK 自有样式、原生导航图标及版本；固定上游与七项 Web 覆盖的散列保持原样。

## 已完成验证

- 42 项 Android 14 隔离模拟器检查通过：真实网关登录、导航与草稿保留、桥接拒绝、外链限制、文件回调、鉴权下载、通知、阅读位置和重启恢复。
- 独立 Instrumentation APK 在生产 Web 页面放入五条示例聊天、消息与模型目录，检查双行标题、输入区高度、展开选项与发送按钮、模型面板位置。生产 APK 不包含该测试资产。
- 已检查聊天列表、聊天、展开选项、模型设置的截图，以及深色模式、320dp WebView 加 130% 文字缩放的截图。输入区没有文档横向溢出，发送按钮可见；模型面板没有横向溢出。模拟器系统键盘实际弹出时，输入框与发送按钮保持在可视范围内；横屏页面适配检查通过。
- 在独立模拟器从正式 0.2.0 覆盖安装，核对测试电脑、主题和持久化标记保留。包名、签名和 Logo 沿用旧版，versionCode 从 3 增至 4。

## 边界

测试使用临时网关与示例数据，未访问个人聊天或发送真实模型任务。模型设置的呈现使用测试目录，保存模型设置仍沿用原有实现。相机扫码、实际公网 HTTPS、厂商键盘、系统大字体与省电策略仍需真机验证。模拟器的 WebView 文字缩放不等同于所有系统字体和显示缩放组合。

正式包附源提交、输入散列 manifest、源码包与 SHA-256 清单。
