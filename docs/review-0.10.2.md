# 0.10.2 审查与验证

此版补齐启动后的本地状态读取，保留原有保存事务和认证边界。

- 配置读取优先使用选中服务商的地址与认证来源，支持带点号的 TOML 服务商名称；缺少自定义环境变量时不使用其他账号的凭据。
- `auth_mode=chatgpt` 时忽略遗留 PAT/API Key 字段。外部认证命令只显示其来源，不执行命令；默认模型未配置时显示沿用客户端默认值。
- 后台检查绑定配置目录和读取前的快照，切换目录或保存后不应用旧结果。自动同步先验证完整快照，再使用同一快照更新界面，避免二次读取遇到文件写入中间态。
- 未保存的配置、登录和模板编辑均保留；原有提交检查继续拒绝覆盖外部修改。读取过程不保存配置或认证；测试使用隔离目录和虚构凭据。
- 进程检测只检查 Codex 客户端进程名。界面明确区分本地文件值、进程存在和在线登录有效性，不将网关健康检查解释成模型可用性。

69 项核心测试通过，覆盖已有自定义服务商导入、普通保存保留路由、凭据隔离、官方登录字段判别、文件删除和内容变化。隔离 UI 检查覆盖自动同步、草稿冲突、认证变化、不完整文件恢复、删除配置，以及原有布局、托盘、网关、启动和更新功能。发布继续从干净提交打包，并执行发布程序、安装后程序及隐私扫描。

配置规则核对：[基础配置](https://learn.chatgpt.com/docs/config-file/config-basic)、[高级配置](https://learn.chatgpt.com/docs/config-file/config-advanced)。当前概览不合并项目、profile 或会话参数，也不读取其他进程的环境变量或操作系统钥匙串。
