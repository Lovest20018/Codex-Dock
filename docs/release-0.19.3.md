# Codex Dock for Windows 0.19.3 本地体验版

工作台新增 **更换模型**。选择新模型后，在同一个窗口核对修改，然后点 **保存并重启 Codex**。Codex 关闭时按钮显示 **保存并打开 Codex**。配置保存会创建加密备份，专用审核需要更新的模型资料会一起核对。

有任务在进行时，可点 **仅保存**。回到工作台后，会看到“模型已保存，等待应用”和“在 Codex 使用新模型”。当前 Dock 会显示待应用状态。下次重新打开 Dock 时，可从 **运行与增强** 应用已保存的配置。

读取列表失败时仍可使用本机已有资料，或手动填写模型。固定审核缺少必需资料时，可以保留原模型，或选择已有资料支持的模型。Codex 退出受阻时，工作台会提示下一步并提供正常重试。

先从旧版 Dock 选择 **停止网关并退出**，然后运行 `CodexDock-0.19.3-Setup-win-x64.exe` 并选择原安装目录覆盖。安装后打开工作台，选一个模型试用。需要回退时，可以覆盖安装 0.19.2 并按需在“备份与恢复”核对、恢复上次配置。[验收说明](review-0.19.3.md)
