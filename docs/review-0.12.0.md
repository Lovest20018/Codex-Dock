# 0.12.0 混合模式恢复审查

按 [Magpie / Codex++ 对比方案](magpie-codex-comparison.md) 的顺序实施：先验证原生身份与路由，再恢复核心、拆出独立 worker、接回可选界面，最后做真实入口检查。参考外部项目的行为与设计，没有复制 Magpie 或 AGPL Codex++ 的实现。

## 路由与凭据

新混合连接使用 `model_provider=openai` 和指向回环地址的 `openai_base_url`。保留本工具拥有的旧 provider 表，供历史会话使用。单独模型凭据用当前 Windows 用户 DPAPI 加密，不进入 TOML；旧 provider 使用本地专用令牌，原生路径验证当前文件中的 OAuth access token。官方令牌与本地管理令牌都不会被发往模型入口。

只转发 models、responses、responses/compact。Cookie、官方账号 ID、项目与 actor 凭据不在请求头白名单。会话连字符头、旧下划线头、后台调用类型和回合元数据可转发；不提供账号、插件或登录接口代理。Origin 请求被拒绝。health/stop 只接受独立本地令牌，官方 OAuth 无权管理 worker。

启用时移除第三方 ChatGPT 后端和认证环境变量，保持官方账号服务路径；请求压缩关闭，向通用 Responses 入口发送普通 JSON。相关原值记入加密连接。切回直连时只还原仍匹配本工具状态的设置；仅当 provider 的地址与令牌都匹配才清理其值，外部改写的表保留。备份恢复仍要求完整快照匹配，避免旧草稿或旧备份覆盖已刷新的登录。

当前支持文件凭据。`keyring`、`auto` 等方式不会被当成已验证文件登录，也不会自动迁移。通过原生登录按钮明确选择文件存储时，在随机临时目录完成登录，结果先进入草稿，保存后才写入。凭据结构检测不等于账号有效、订阅有效或在线鉴权成功。

## 网关与兼容边界

每个配置目录一个 worker，文件锁限制并发启动；worker 读取保存的连接，编辑器退出不结束。定期检查连接是否禁用或替换，health 带协议版本，编辑器能停止旧协议 worker 并重启。当前协议版本为 3。手动停止在本次编辑器运行中保持，重新打开工具可恢复。重登 Windows 后仍需打开工具或开启工具的自动启动。

HTTP 建连/响应头限时 60 秒，流中空闲 5 分钟后取消；WebSocket 建连 30 秒、空闲 5 分钟。保留 64 MiB 请求体/消息边界。网关不重放已经开始的请求，不进行跨后端续接。WS 上游 404/405/426/501 保留为对应握手状态，由原生客户端决定是否转 HTTP。入口鉴权失败转换为模型错误，避免触发官方 OAuth 刷新，并保留上游状态及经过筛选的错误码、请求 ID。诊断不记录提示词、凭据、完整上游错误正文或异常消息。

模型目录支持标准 `data` 数组和 Codex 原生 `models` 数组；原生能力保留，缺失能力使用保守默认，不虚构 Fast、搜索或多模态支持。目录受体积、数量和去重限制。目录成功不等于全部模型能力可用。

## 隔离检查

核心回归共 74 项，包含设置/保存/备份原有检查，以及混合身份、旧连接升级与再次保存、外部 provider 保留、目录、401/403/429/5xx、会话头、SSE 取消、WS 转发与 426 握手、进程脱离启动器、停止/重启/禁用。设置 `CODEX_CONFIG_TEST_CLI` 后的两项检查使用安装中的原生 Codex app-server，分别覆盖内置 openai 与旧 provider 的 ChatGPT 身份、模型目录、推理、Fast 参数和凭据隔离。全部使用虚构登录与本机模拟服务。

实际 WPF 界面检查共 91 项，覆盖 PAT 默认、可选混合面板、保存后重读、普通设置不改官方登录、固定保存栏、离线保存、草稿冲突、旧版转换、编辑器关闭后 worker 继续及显式停止。窗口检查含 960×640、深浅主题和缩放模拟；截图确认可滚动表单及底部保存操作可见。

## 真实入口检查（2026-10-30）

仅只读使用当前已选择模型入口及其独立凭据，通过隔离端口/目录验证。没有修改当前用户配置，没有使用真实官方 OAuth，没有消耗官方推理额度。模型入口请求会产生该入口的用量。

| 项目 | 结果与限制 |
| --- | --- |
| 模型目录 | 首次 502；复查原始结构与网关转换均 200，返回 8 个模型。记录首次失败，不据后续成功宣称入口稳定 |
| 连续回复 | HTTP 两轮均 200，均完成且有文本 |
| 压缩 | responses/compact 返回 200，含 compaction 项 |
| 函数工具 | 收到 function_call；提交虚构 function_call_output 后续接完成，均 200 |
| WebSocket | 原始握手与补全 Codex Beta 头后均被入口返回 426；本机模拟 WS 帧、凭据隔离测试通过 |
| 原生 app-server | 虚构 ChatGPT 身份，两轮完成，网关捕获 Fast 参数；再次启用两项 WS 功能后仍完成两轮，最终上游 200 |
| 原生 shell | 曾要求原生客户端执行固定输出命令，但未观察到 commandExecution 完成事件；不能据函数协议通过宣称原生 shell 验收通过 |
| Fast | 只确认 priority 参数经过网关，未验证实际加速、计费或所有模型的支持情况 |
| 官方审核、记忆、图片、桌面客户端全流程 | 尚未使用真实官方登录逐项验收；不保证任意入口全部可用 |

脱敏原始记录保留在本地忽略目录 `artifacts/research/` 下的 mixed-recovery-live、mixed-recovery-native-live、mixed-recovery-tools。研究目录及其隔离 homes 不进入源码包或二进制发布包。

正式交付另以实际自包含发布程序和隔离安装后的程序运行相同界面检查，检查 manifest、安装/卸载、SHA-256 及隐私扫描。以上能力边界不随打包通过而扩大。
