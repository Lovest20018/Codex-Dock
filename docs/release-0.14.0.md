# Codex Dock 0.14.0

手机连接升级为完整 Codex 工作台，复用 Codex Mobile Bridge 2.1.7 的 Web 和服务端。新增聊天/项目/分支、模型与权限、富文本、图片附件、文件预览、Git、终端、CLI / WSL / SSH、账号接入、通知和安卓协助更新。具体执行端限制见 [功能对照](mobile-upstream-comparison.md)。

电脑手机页新增“管理 Codex 接入”，使用原上游账号及 CLI / WSL 面板。管理链接仅本机、60 秒一次有效，页面授权 30 分钟。手机查看和切换已保存的账号，登记仍在电脑完成。其他 AI 客户端按本轮范围禁用；现有 HTTPS 域名和反代方式继续使用。

保留 0.13.3 共享来源错误登录不会撤销已有授权的修复。设置协议升级为 4；旧 1/2/3 设置兼容，设备记录保留。旧发送账本迁移但不自动重发；首次进入相同网关时可确认账号后导入旧浏览器草稿。

## 更新与回退

1. 在旧 Dock 页面或托盘停止手机网关，再从托盘退出 Dock。退出编辑器本身不会停止后台。
2. 备份安装目录、当前 Codex 配置目录及 `%LOCALAPPDATA%\CodexConfig\mobile`。新增的账号、远端登记和通知设置包含私有数据，备份留在本机。
3. 核对包旁 SHA-256，安装新版或完整解压便携包，保留整个 `mobile` 目录。不要混用旧版 worker 和新版运行时。
4. 启动手机网关，检测 HTTPS 入口，刷新手机网页。反代需透传 SSE，并为终端 WebSocket 设置 Upgrade / Connection。
5. 核对历史、草稿、设备，再按需显式创建或继续任务。首次账号切换及 CLI 初始化按原上游提示确认。
6. 回退先停止新版服务，再恢复旧安装和升级前数据备份。原操作文件保留供回退，新工作台的账号/队列等设置不能由旧精简版管理。0.13.2 及更旧版本仍有共享来源登录问题。

验证记录见 [审查](review-0.14.0.md) 和包内 verification；本版没有操作当前真实会话或修改现有反代，安卓真机、公网与真实模型调用需在使用环境验收。
