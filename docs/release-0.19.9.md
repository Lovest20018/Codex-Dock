# Codex Dock 0.19.9

## 客户端增强

- 适配 Microsoft Store 版 Codex **26.1117.3838.0** 的模块加载器。速度兼容可以读取当前选中模型原有的 Fast / Ultrafast 档位，旧聊天接续可在同一个 Codex 实例中启用。
- 处理刷新期间失效的调试暂停，在新页面继续加载增强。
- 旧聊天接续遵循 Codex 的取消信号。在卸载聊天、迁移供应商索引和发送前核对取消状态，取消后停止尚未开始的操作。

## 覆盖升级

运行 Windows x64 安装器并选择原安装目录。安装器会请求正在运行的 Dock 正常退出，并停止同一安装目录的网关。便携版请解压到独立目录，并保留整个目录。

升级后，在 **高级工具 → Codex 与增强** 中按需启用增强，然后点击 **打开或重启 Codex 并应用**。发布附件包括安装器、便携 ZIP、源码、SHA-256 和安装验证报告。 [验收范围](https://github.com/Lovest20018/Codex-Dock/blob/v0.19.9/docs/review-0.19.9.md)
