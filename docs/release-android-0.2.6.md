# Lovest Code 0.2.6

从 **电脑** 页可以扫描 Windows Codex Dock 生成的配对码。连接探测中按返回键可回到电脑列表，再选一台电脑。已打开的聊天保留在原电脑，未发送的文字跟随原账号草稿。

配合 Windows Codex Dock 0.19.6 的手机网关，可在聊天中打开交互图表，切换全屏后关闭预览。图表的追问可以放入输入框，由你决定何时发送。聊天输入框提供 **/** 命令，原生消息时间会随历史显示。

应用 ID 为 io.github.lovest20018.codexdock，版本号为 0.2.6，内部版本号为 9。升级时使用同一发布签名的 APK 覆盖安装。
