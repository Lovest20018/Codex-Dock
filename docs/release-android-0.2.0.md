# Lovest Code Android 0.2.0

聊天、电脑、我的采用三项底部导航，聊天详情和网页弹窗打开时收起导航。查看电脑或设置保留当前 WebView、文字草稿、工作台和下载；返回根页面将 App 放入后台。

电脑页使用紧凑列表，添加入口提供扫码和手动地址。电脑详情集中连接、账号与接入、诊断、改名和移除。我的页面提供通知、主题、语言、阅读设置、当前电脑的聊天提醒规则和版本。阅读与网关提醒仍复用电脑工作台，明确区分本机通知权限。

安卓随包提供独立适配脚本，握手成功才隐藏重复的网页导航。聊天列表增加通知入口，审批请求提供快捷定位。沿用现有发送确认和排队逻辑；请求结果未知时继续核对，不自动重发。首次使用显示连接引导，后续启动按已保存的电脑与聊天定位恢复；阅读位置依照现有账号、执行环境和聊天作用域保存。

切换电脑或刷新前保存文字草稿。无法确认草稿保存时保留当前页面并显示原因；存在未发送附件时，用户可以返回当前聊天或明确放弃附件。切换标签不需要放弃附件。

包名、签名与 Logo 沿用 0.1.1；versionCode 从 2 增至 3，可以覆盖安装。APK 为 `LovestCode-Android-0.2.0.apk`。Windows Dock 继续使用 0.15.1，无需更新服务端协议；普通浏览器页面不受 APK 适配影响。

验证入口为 `tests/android/run-smoke.py`，包含真实 Android WebView 登录、三项导航、主题、文件选择、下载、通知、草稿作用域和旧版覆盖升级。测试使用隔离模拟器及无模型运行时的临时网关；模拟的输入和导航数据不代表真实 Codex 任务验收。真实扫码、公网 HTTPS、厂商键盘及后台策略仍需真机验证。
