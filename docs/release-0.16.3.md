# Codex Dock for Windows 0.16.3

配置模板与手动修改采用统一流程：选择修改 → 查看差异 → 确认写入本地文件。

- 手动修改后点击“查看并确认修改”或按 Ctrl+S，显示实际目标文件与修改前后值；在确认页直接写入，无需关闭预览再寻找保存按钮。
- 模板选择后直接进入确认页，保留所在页面。返回调整时撤回本次临时预览、保留此前草稿与勾选；调整后重新确认只写入所选项目。
- 区分内置推荐、本地已编辑方案、本地现值及 Codex 默认。“保存方案”只修改本机方案库；恢复默认明确表示移除该项本地覆盖。
- 保存成功后重新读取配置，显示结果、备份入口与重新打开 Codex 的生效提示。格式错误、组合校验或外部文件冲突会阻止写入，并保留修改。
- 修复已有 `[features]` 或内联表时新增多层配置字段生成重复定义的问题，包括 V2 子代理并发设置；保留其他设置、注释、换行与已有开关。

本版只更新 Windows，Android 保持 [0.2.4](https://github.com/Lovest20018/Codex-Dock/releases/tag/android-v0.2.4)。升级保留用户配置和本机模板库，不会把推荐方案自动写入 config.toml。

## 安装与更新

本页提供 `CodexDock-0.16.3-Setup-win-x64.exe`、完整便携 ZIP、对应源码、`SHA256SUMS-0.16.3.txt`、安装验证报告和 release manifest。

等待正在执行的任务结束，备份程序目录、Codex 配置目录与 `%LOCALAPPDATA%\CodexConfig`。核对 SHA-256 后，在 Dock 设置或托盘选择“停止网关并退出”，再运行安装器。软件内更新会先停止当前配置的两个网关。安装器保留原有配置与电脑授权，无法核对或正常停止目标手机后台时会中止覆盖。

便携版应完整解压并保留整个 `mobile` 目录。更新后可先修改一个普通设置，确认目标路径与前后值，再验证保存成功与备份恢复。需要手机连接时，重新启动手机网关并检查原 HTTPS 入口。

回退时停止网关并退出，恢复 0.16.2 完整程序目录；如需回退配置，在备份恢复页恢复对应备份。审查与验证边界见 [0.16.3 审查](review-0.16.3.md)，实际安装包验证结果以同页附件为准。
