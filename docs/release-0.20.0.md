# Codex Dock 0.20.0

## Windows 界面

- 在 **模型与行为** 中直接读取、筛选并选择服务模型，也可以手动填写模型 ID。**连接** 页保留当前模型与选择入口。
- 从 **手机连接 → 连接与配对** 依次保存入口、启动服务、检测 HTTPS 和扫码。完成后显示连接摘要。
- 设置、模型网关和托盘共用 **退出…** 对话框，可选择仅退出 Dock，或停止网关并退出。
- 高级工具显示页面路径，核对或保存时底栏保留当前状态和操作。首页将增强偏好错误引导到重新读取，将配置错误引导到恢复工具。

WinUI 合并重复刷新并保留切页时的草稿。正式包使用独立的启动验证，完整界面回归在测试构建中运行。

## 覆盖升级

在 Windows x64 上运行安装器并选择原安装目录。安装器会请求 Dock 正常退出，并停止该目录的模型和手机网关。若有待处理修改，先在 Dock 中核对或撤销，再继续安装。便携版请完整解压到独立目录。

使用原配置与加密备份即可继续工作。需要回退时，保留配置与备份，退出 Dock 及本机网关后运行上一稳定版安装器。安装器、便携包和源码可使用发布页的 SHA-256 文件校验。 [验收范围](https://github.com/Lovest20018/Codex-Dock/blob/v0.20.0/docs/review-0.20.0.md)
