# Codex Dock 交付说明

当前 0.12.1 为 Windows Codex 配置编辑器。面向使用者的完整操作见 [README](../README.md)。

默认打开 PAT 连接页，服务地址、凭据与模型集中编辑。可选“官方账号 + 独立模型入口”展开原生登录与网关诊断。保留概览、常用行为、全部配置、模板、备份、托盘、开机启动和 GitHub 更新。固定保存栏、Ctrl+S 和离线保存保持。

旧版混合连接支持显式升级，也可选择转换直连。混合模式保留内置 openai 身份与旧 provider 兼容入口；网关独立运行，编辑器退出后继续服务。切换直连仅清理匹配本工具地址与本地令牌的 provider 值。原用户目录、安装 AppId、加密参数和备份格式保持兼容。

发布采用自包含 Windows x64 程序，提供安装器、便携 ZIP、源码 ZIP 和 SHA-256 清单。发布程序与隔离安装后的程序均执行 UI 检查，manifest 记录源提交及散列。隐私扫描排除个人认证、配置、备份和构建缓存。

程序自动识别修复见 [0.12.1 审查](review-0.12.1.md)。布局、保存、转换和真实线路边界仍见 [0.12.0 审查](review-0.12.0.md)。docs 中旧版设计和版本记录仅供维护参考。
