# Codex Dock 交付说明

当前 0.11.0 为 Windows PAT 配置编辑器。面向使用者的完整操作见 [README](../README.md)。

默认打开 PAT 连接页，服务地址、凭据与模型集中编辑。保留概览、常用行为、全部配置、模板、备份、托盘、开机启动和 GitHub 更新。已移除 ChatGPT 登录、本地网关与网关代理功能；保存配置后，Codex 直接读取本机文件。

旧版混合连接仅作兼容读取。点击保存时创建加密备份并转换为直连，不在打开窗口时修改原配置。进程与主程序集为 CodexDock；原用户目录、安装 AppId、加密参数和备份格式保持兼容。

发布采用自包含 Windows x64 程序，提供安装器、便携 ZIP、源码 ZIP 和 SHA-256 清单。发布程序与隔离安装后的程序均执行 UI 检查，manifest 记录源提交及散列。隐私扫描排除个人认证、配置、备份和构建缓存。

布局、保存与转换审查见 [0.11.0 审查](review-0.11.0.md)。docs 中旧版设计和版本记录仅供维护参考。
