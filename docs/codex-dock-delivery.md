# Codex Dock 界面改版交付

2026-10-28。基于“状态总览”视觉方案实施。

后续界面检查已修复模板页签覆盖正文、长路径撑高页头、小窗口导航与模型列表挤压等问题，详情见 [界面布局检查与修整](ui-layout-review.md)。

## 界面与品牌

- 软件显示名称为 Codex Dock，采用停靠接口图标，提供独立单色托盘标识。
- 默认概览：显示已保存连接、模型、官方凭据读取状态和本地网关状态，不把本地监听等同于上游推理可用。
- 导航调整为概览、连接与账号、模型与行为、网关与网络、模板与备份、全部配置、应用设置与帮助。
- 默认模型与获取模型入口迁入模型页，模型行为按速度、搜索与上下文、执行权限、隐私分组。
- 模板与备份通过页签切换；完整字段编辑和模板库继续复用原有组件。
- 网关运行信息优先展示，计数收起到运行详情；窗口与托盘说明迁到应用页。
- 配置目录与持久反馈在页头；仅有配置草稿时显示底部统一保存栏，编辑模板时使用模板独立操作栏。
- 新版提供灰白/石墨深色主题和蓝色操作强调。

## 兼容性

界面进程与网关子进程统一使用 CodexDock.exe，主程序集为 CodexDock.dll；核心命名空间和数据兼容标识继续沿用 CodexConfig。用户数据路径、配置格式、保留 provider ID、DPAPI 加密参数和备份格式保持兼容。安装器展示名和快捷方式名称改为 Codex Dock，继续使用原 AppId 与已有安装目录检测机制。

关闭窗口继续收起到托盘，草稿保留；最小化保留任务栏入口；托盘退出会处理草稿并停止网关。HTTP 代理设置、旧网关替换与后台进程退出机制继续保留。

## 验证

最终发布程序执行隔离界面检查，覆盖跨页面草稿、保存与恢复、模板库、字段搜索、缩放、深浅色、代理、托盘及网关退出。所有认证和连接示例使用虚构凭据，不修改当前 Codex 配置。

## 使用

解压便携包后运行 `CodexDock.exe`，窗口显示 Codex Dock。先退出旧配置工具，再运行新版，避免两个编辑器同时管理同一配置。此包含 .NET 运行时。
