# Codex Dock for Windows 0.17.0

保存配置后，可在结果页选择“重启 Codex 并应用”，确认程序和配置目录后正常退出并重新打开 Codex，再新建聊天核对。

- 更新配置目录至 1064 条结构定义，补入 61 条路径和中文资料、枚举、生命周期及核查版本提示；新增 Guardian V2 弹性预算组合校验。
- 社区模板不再默认勾选关闭统计，保留用户已有配置和已编辑的本机方案。
- 外部 HTTP 模型入口增加按主机和端口绑定的明文确认，获取模型与网关 HTTP / WebSocket 共同校验；Dock 的明文请求使用直连，撤销并保存后停止相应模型网关。
- 保存成功页提供“重启 Codex 并应用”和“查看配置来源”。取消退出、超时、实例变化或保存后文件被外部修改时停止重启，保留已保存结果。
- 支持识别 Windows 商店版 Codex 的桌面程序，并在启动时使用本次保存的配置目录和登录服务地址。

重启不增加旧内核对新字段的支持。新增资料对应 Codex `0.168.0-alpha.4`，较旧内核需先核对支持情况；项目、Profile 和组织要求仍可能覆盖用户文件。只确认桌面进程重新打开，配置效果需在新聊天核对。

本版仅更新 Windows，Android 保持 [0.2.4](https://github.com/Lovest20018/Codex-Dock/releases/tag/android-v0.2.4)。升级不会自动启用新增字段，也不会覆盖本机自定义模板。

## 安装与更新

附件包含 `CodexDock-0.17.0-Setup-win-x64.exe`、完整便携 ZIP、源码、`SHA256SUMS-0.17.0.txt`、安装验证报告及 release manifest。

等待当前任务结束，备份 Codex 配置目录、程序目录及 `%LOCALAPPDATA%\CodexConfig`。核对 SHA-256，在 Dock 设置或托盘选择“停止网关并退出”，再运行安装器。安装器保留配置与电脑授权；无法核对或正常停止目标手机后台时会中止覆盖。便携版完整解压并保留 `mobile` 目录。

升级后可修改一个普通设置，核对目标文件与前后值，再验证保存、备份恢复及重启入口。使用外部 HTTP 地址时，先在连接页确认对应站点；需要手机连接时重新启动手机网关并检测 HTTPS 入口。撤销 Dock 的 HTTP 确认不会接管 Codex 自行发送的直连请求，需停止任务或更换地址并重新打开。

回退时停止网关并退出，恢复 0.16.3 完整程序目录；如需回退配置，使用备份恢复。详细行为与验证边界见 [0.17.0 审查](review-0.17.0.md)和[实施记录](superba-reuse-implementation-2026-11-11.md)，实际安装验收以发布附件为准。
