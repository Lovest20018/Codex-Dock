# Codex Dock for Windows 0.16.2

手机网页刷新时保留阅读位置，并增加图片原图保存和第三方模型兼容性。本轮选择性移植 Codex Mobile Bridge 2.2.0 的修复，基础快照仍为已审查的 2.1.7。

- 聊天刷新、追加回复、前插历史和重排消息时保留展开的思考/工具卡片及滚动位置；切换聊天时重新建立阅读状态。
- 修复安卓首次点击复制深度链接无效的问题，复制成功后关闭会话菜单。
- 图片预览增加“保存到本地”，上传图片下载原图，工作区图片复用授权文件下载；保留登录、会话、文件与来源校验。
- 支持中文等 Unicode 模型 ID；第三方服务没有思考摘要时展示其有效思考内容，并支持增量更新。继续拒绝空白、控制字符、超长 ID 和异常增量索引。
- 保留现有固定 HTTPS 地址、Codex-only、账号范围草稿、三页导航及未知发送结果不自动重试。
- 侧栏和“软件更新”的版本均显示正在运行的程序版本；补充安装包级回归，防止旧版侧栏固定版本号的问题再次出现。

完整使用本批功能请配套安装 [Lovest Code for Android 0.2.3](https://github.com/Lovest20018/Codex-Dock/releases/tag/android-v0.2.3)。独立通知、安卓冷启动与原生图片下载支持由该 APK 提供。原始移植范围及验证边界见 [移植记录](mobile-upstream-backport-2026-11-09.md)。

## 安装与更新

本页提供 `CodexDock-0.16.2-Setup-win-x64.exe`、便携 ZIP、对应源码、`SHA256SUMS-0.16.2.txt`、安装验证报告和发布 manifest。

等待正在执行的任务结束，备份程序目录、Codex 配置目录与 `%LOCALAPPDATA%\CodexConfig\mobile`。核对 SHA-256 后，在 Dock 设置或托盘选择“停止网关并退出”，再运行安装器。更早版本可分别停止两个网关后退出。安装器保留原有目标目录、用户配置与电脑授权；不能核对或正常停止目标手机后台时会中止覆盖。

便携版应完整解压，保留整个 `mobile` 文件夹。更新后打开 Dock 并启动手机网关，检查 HTTPS 登录、阅读、复制与图片保存；模型目录可使用已有接入按需读取，不要求切换接入或启动真实任务。

回退时停止网关并退出，恢复 0.16.1 完整程序目录及需要恢复的个人数据备份。源码审查见 [0.16.2 审查](review-0.16.2.md)，实际安装包的校验与覆盖安装结果以同页附件为准。
