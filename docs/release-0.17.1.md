# Windows 0.17.1 · 模板应用逻辑修正

本版解决模板“不勾选”容易被误认为关闭功能、本地旧方案遮住新版内置配方的问题。

- 每项显示本地值、已有草稿、方案值和本次结果；勾选写入方案值，不勾选保留现值或草稿。新增“选择全部方案值”和“全部保留”。
- Krill 社区方案与固定的 Superba alpha.15 六项 PAT 配方对应；旧上下文、历史笔记及隐藏警告默认不选，统计配置不再混入该配方。
- 本地编辑过的方案可直接“查看本版内置方案”，用于本次配置写入；本地方案及原来源信息保留。
- 新增“停用旧上下文与历史笔记”方案，明确将旧上下文管理、预算和历史笔记三项写为 `false`。表格式上下文配置不会被模板替换成布尔值，复制方案也受同样保护。
- 继续使用差异确认、加密备份和恢复流程，取消确认保留原草稿，重复应用相同值不生成多余修改。

## 升级与使用

从 Windows 应用“检查更新”或本 Release 下载安装器覆盖升级。安装器保持既有 Codex 配置和本机模板库；升级不会自动应用任何方案。

进入“模板与备份”选择方案，核对每项结果和目标文件，再确认写入。Krill 上游配方中的旧功能值仍为 `true`；若要按停用通知关闭，应选择“停用旧上下文与历史笔记”，不能仅取消勾选。保存成功后重新打开 Codex 并新建聊天核对。

修改配置前会自动创建当前 Windows 用户加密的备份，可在“备份恢复”恢复上一次配置。安装包升级本身不替代配置备份；需要退回程序时可使用上一版安装器，恢复配置仍通过备份入口处理。

本地核心回归 111/111、完整界面检查 151 项通过。发行附件包含对应提交的源码、SHA-256、安装验收报告及发布清单；便携版和安装后程序由发布流水线再次验收。
