# Codex Dock 0.13.1

修复手机服务只能接受本机代理、群晖等设备无法连接的问题。

- 手机连接新增 **局域网反向代理 IP**。填写准确的代理 IPv4 后启用局域网监听，只接受该代理和本机连接；留空保持原回环监听。
- 私有管理端口保持仅本机，公网域名、Origin、CSRF、Cookie 和登录校验继续生效。只信任配置代理转发的客户端地址。
- 本机 `http://127.0.0.1:13090/` 显示诊断页及 HTTPS 入口；不会在 HTTP 上提供登录。
- HTTPS 检测分别提示 502 的目标/网络问题及 403 的 Host/来源问题。
- 旧版加密手机设置自动兼容，端口默认 13090 且可改；更改代理接入方式保留原账号、密码和设备授权。

升级前停止手机服务并从托盘退出旧 Dock。安装新版后填写代理 IP，密码留空沿用，再保存并启动。群晖反代目标为 Windows 电脑可达的 IP:13090，保留外部 Host（含 HTTPS 端口）。不同网段需有现存路由或通道，软件不自动配置路由、FRP 或防火墙。

验证和已知限制见 [0.13.1 审查](review-0.13.1.md)，操作步骤见 [手机连接说明](mobile-connection.md)。

38 项手机后端测试、80 项核心回归、101 项桌面 UI 检查通过。尚未确认实际群晖到电脑的网络链路，也未进行安卓真机登录验收。
