# Codex Dock 0.15.1

- 修复保存英文语言偏好后页面不能启动；设置分组按稳定的资源标识识别。
- 修复待确认或拒绝提示遮住新草稿校验错误；仅隐藏与投递警告重复的错误。
- 聊天标题栏“更多”正确打开会话菜单。
- Windows 的“PAT 连接”改为“连接与账号”，覆盖 PAT / API 与官方账号登录。
- 窗口顶部常驻本地模型网关、手机网关状态，分别显示运行中、已停止、操作中或未确认。点击进入对应页面，刷新只读取状态。监听端口但无法取得可信健康响应时显示未确认。
- Web 和安卓加载的工作台保留 Codex 聊天、审批、Git、文件、终端、WSL / SSH；清理其他 AI 偏好、上游 Codex 更新及动态网络部署入口，服务端同时拒绝相应更新和网络部署 API。本机接入管理继续支持官方账号和 API。

安卓仍兼容上游 APK，本版没有重建原生壳。旧 APK 自带的原生更新菜单不受网页控制；Dock 不再提供电脑协助下载上游 APK。[独立安卓壳方案](android-dock-shell-plan.md)说明下一阶段边界。

## 更新与回退

等待任务结束，停止手机网关并退出 Dock。备份安装目录、Codex 配置与 `%LOCALAPPDATA%\CodexConfig\mobile`，核对 `SHA256SUMS-0.15.1.txt` 后安装或完整解压便携包。启动后强制刷新网页，核对网关状态和待确认消息。更新不撤销已受理的消息。

安装目录继续使用 `%LOCALAPPDATA%\Programs\Codex Config` 或已登记的路径。本版没有修改数据协议；回退时先停止网关、退出程序，再恢复 0.15.0 的完整程序目录。验证范围见 [审查记录](review-0.15.1.md)。
