# 模型、速度与专用审核

本页对应 Windows 0.18.0，覆盖模型、专用审核、能力目录及应用状态。正式产物与安装验证见对应 Release 附件。

## 常用设置

“模型与行为”按模型、推理强度、速度、自动审核分区。默认主模型和连接页共用一份草稿；完整原始字段、配置来源和 Profile 仍在“全部配置”。执行、搜索、上下文和功能开关收在“更多行为设置”。

推理强度与速度分别设置。Max、Ultra 是推理选项，Fast、Ultra Fast 是速度选项。档位由当前能力目录提供；当前聊天仍可以在 Codex 中单独选择。

## 固定自动审核模型

1. 在“模型与行为 → 自动审核”选择“帮我批准”，勾选“固定使用 codex-auto-review 审核”。没有审批策略时设置 on-request；已有沙箱与细分审批策略保持。
2. 使用当前原生目录，或从同页导入当前模型服务提供的能力 JSON。只有模型 ID 的列表不能用于推断工具、速度和审核能力。
3. 点击“查看并确认修改”。确认页同时列出配置、生成的能力目录和管理记录；确认写入后创建加密备份。
4. 保存后重新打开 Codex，在确实需要审批的操作中核对真实后台。审核模型与主模型使用同一个服务和对应凭据；这里不配置另一套审核账号。

如果检测到此前手工固定的专用审核配置，页面显示“可同步纳入管理”。点击“同步模型目录”后，通过上述保存流程接管，原文件保持。勾选审批人不是网络可用性测试；审核模型不可用时，原生审核失败并阻止执行，不回退主模型。

原生实现采用每个非审核模型的 `auto_review_model_override`。普通代码审查 `/review` 的 `review_model` 是另一项设置。

固定策略适用于受管目录中列出的模型。若在原生 Codex 中另选了目录外的模型，需要重新核对；Dock 不把没有映射的模型标为已固定审核。

## 目录同步与恢复

- “同步模型目录”重新读取已登记的来源，生成新的待保存版本，并保留专用审核映射。
- “读取客户端目录”明确使用本配置目录的 models_cache.json；“导入能力目录”选择用户提供的原生文件。
- 来源文件变化时只显示“有更新待同步”，不会静默覆盖配置或运行模型任务。
- 管理记录包含来源、摘要、连接标识和更新时间；不保存凭据。生成的目录只保留 models 数据，并保持模型内的原有能力和未知字段。
- 切换服务或选择目录外的主模型时，固定审核的保存会被阻止，要求为当前服务导入包含该模型的目录。
- 每次确认保存将目录依赖和管理记录纳入原有加密备份。恢复可重建已经缺失的旧受管版本；缺失的外部源文件恢复为本目录的独立副本，不覆盖外部文件。
- 目录历史版本不自动清理，避免损坏配置与备份中的引用。用户自己的外部目录不会按文件名自动认作 Dock 文件覆盖。

受管文件位于配置目录的 `codex-dock-models/<内容摘要>.json`；索引为 `codex-dock-catalog.json`。这些是用户数据，已排除在源码、安装和发布隐私检查的允许范围之外。

## 速度兼容与应用状态

速度兼容主入口已移到“模型与行为 → 速度”，应用设置保留跳转。当前设置依旧按配置目录保存、默认关闭；现有草稿需先确认保存，才能重新打开 Codex 并应用。需保持 Dock 运行，托盘与退出规则见[速度兼容说明](desktop-speed-compatibility.md)。

概览显示文件保存状态、进程情况和通过 Dock 重新打开的时间，并提供统一应用入口。保存结果、速度卡片与备份恢复使用同一[应用面板](codex-restart-flow-2026-11-12.md)，显示阶段进度、外部变更核对和兼容重试。混合连接在退出 Codex 前准备模型网关；兼容加载失败后可单独重试。重新打开成功不自动标记为当前聊天已采用，更不等于服务端已经提供对应档位或费用。

“查看聊天参数”只列出当前配置目录中的近期记录，由用户明确选择一份读取。仅返回模型、推理、速度、审批方式和时间等白名单元数据；不展示提示词、命令或凭据。解析会话内 configuration_update 时将其作为后续推理选择，不把顶层缓存基线误认作当前选择。

诊断没有实际审核模型证据时显示未提供，不拿配置目标冒充调用记录。本机模型网关的统计属于经过该网关的请求；API 直连不经过网关，不能用该网关的计数作为直连统计。

## 验证与边界

实现记录与分阶段测试证据见 [0.18.0 审查](review-0.18.0.md)。当前内核 `0.167.0-alpha.4.1` 的隔离测试已验证生成目录、专用审核成功、专用模型 404 阻止执行，以及主请求 Ultrafast 保持。测试使用虚构凭据和本机模拟服务，不在保存或刷新时调用付费模型。

本轮只更新 Windows Dock，不修改 Android、Max／Ultra 的原生映射或真实用户运行中的 Codex。当前本机原有配置保持，纳管操作仍由使用者在新界面中预览和确认。
