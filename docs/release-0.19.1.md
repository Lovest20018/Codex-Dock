# Codex Dock for Windows 0.19.1

修复 Codex 已打开时，点击“打开／重启 Codex 并应用”会把旧窗口收起到托盘、随后报退出超时的问题。

- 正常重启改为调用 Codex 的“文件 → 退出”菜单，等待旧实例及其辅助进程退出后再打开。
- 已收起或最小化的所选实例会先恢复主窗口，继续使用正常退出流程。
- 等待保存、取消退出或无法核对菜单时显示原因。“结束所选实例”仍需单独确认，不会由超时自动触发。
- 安装和打包检查要求包含正常退出组件，保留其他实例、资料目录与 CLI 会话的隔离检查。

本次提供本地修复安装包。先在旧版 Dock 选择“停止网关并退出”，再运行 `CodexDock-0.19.1-Setup-win-x64.exe`，选择原目录覆盖安装，无需先卸载。用户配置、认证及聊天不随包分发；安装包包含运行库与手机后台。

首次使用的新 Codex 资料需先完成或跳过首次使用向导，进入带有应用菜单的主界面。任务尚在运行时，应先保存并完成任务再重启。若 Codex 弹出保存或退出确认，按提示处理后继续。

如需回退，停止网关并退出 Dock 后可覆盖安装 0.19.0。此修复不更改配置格式。验收范围见 [本版审查](review-0.19.1.md)。
