# Codex Dock 0.15.0

Web / 手机聊天界面与本机接入管理页按 [UI 方案](ui-optimization-plan.md) 完成调整。

- 聊天输入区集中展示消息、附件、模型、权限与发送，低频选项归入“更多”；已选发送方式、工作模式和 Skill 继续可见。Enter 换行，Ctrl / Cmd + Enter 发送，输入法合成期间不提交。
- 消息附近显示正在发送、已接收、已排队、明确未接收或结果待确认。待确认时可查看消息管理核对原请求；相同待确认提交不会新增发送。保留确认后清原稿和新草稿保护。
- 聊天列表区分加载、未接入、无聊天、筛选无结果与读取失败；搜索独占一行，筛选可展开，底部固定“连接与接入”和“设置”。
- 设置分为外观与阅读、聊天与通知、连接与诊断，标注当前浏览器或当前网关范围；外观重置仅重置浏览器偏好。连接页分开显示网页到网关、网关到 Codex 和账号 / API 信息。
- 本机接入页显示当前接入，使用已保存接入、API 编辑、应用与 WSL 三个标签；Key 默认掩码，切页保留未保存表单，Desktop / CLI 共用和 WSL 独立范围在操作前说明。

Windows 原生主窗口功能保持当前范围，本版界面改动面向 Web 工作台和本机管理页。账号、配对、CSRF、端口、反代与发送协议沿用既有规则。

## 更新与回退

1. 等待任务结束，从页面或托盘停止旧手机网关，再从托盘退出 Dock。
2. 备份安装目录、Codex 配置及 `%LOCALAPPDATA%\CodexConfig\mobile`，备份留在本机。
3. 对照 `SHA256SUMS-0.15.0.txt` 核对下载文件，运行安装器，或把便携包完整解压到独立目录。保留整个 `mobile` 文件夹。
4. 启动网关，浏览器强制刷新以加载新样式，确认聊天、草稿和接入范围。检查待确认消息后再继续发送。
5. 回退时先停止网关并退出 Dock，再恢复旧程序。0.14.1 与本版的数据协议相同；界面偏好仍保存在当前浏览器，回退不代表撤销已受理消息。

安装器沿用当前用户安装目录 `%LOCALAPPDATA%\Programs\Codex Config`，升级可沿用已登记路径；配置与用户资料不随发布包提供。验证、渲染测量与设备限制见 [审查记录](review-0.15.0.md)。
