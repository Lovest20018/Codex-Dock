# Windows 启动、配置来源与 Profile 迁移记录

本轮补齐 WinUI 预览的 Windows 设置、配置来源与独立 Profile 页面。WPF 与 WinUI 共用应用服务，WPF 仍是默认交付入口；本轮未修改安卓资源、真实启动注册或用户运行服务。

## 行为

- 开机启动绑定当前程序和配置目录，登录 Windows 后收起到托盘。开关独立保存，不改模型草稿。同一用户共用一个 `CodexDock` Run 项，替换其他程序或目录前先确认，确认后复核观察到的命令；关闭不会删除其他注册。路径过长或写入失败时保留原状态并提示。
- 配置来源通过用户明确选择的本机执行端读取已保存文件，展示文件值、执行端读取值、来源及作用范围。未保存的主配置和 Profile 草稿不参与，读取不会开始聊天或执行工具。支持取消、筛选与分页；条件或文件改变时清除旧结果，内核不支持 Profile 来源时显示未确认。
- 独立 Profile 只展示和编辑普通模型与行为 TOML，原文件中的连接、权限、私密或不可编辑字段保留。保存和恢复先显示具体差异、目标与来源，确认副本只可提交一次；外部改动及确认期间草稿改变会阻止写入。Profile 与主草稿独立，切换页面保留编辑，离开工作区、退出或增强启动前处理未保存选择。
- 完整回归还发现原网关收到 WebSocket 正常关闭后立即中止两端的时序问题，可能截断已转发的尾部消息。现先转发关闭帧并等待确认，最长两秒；取消、超时与连接替换保留原清理规则。原分段消息回归已加强为同时检查正常关闭帧与确认握手。
