# 0.11.0 PAT 编辑与保存审查

手动输入模型时，原界面只监听选中项变化，未监听可编辑输入框的文本变化，可能没有及时将修改标记为草稿。模型列表请求还共用忙碌状态，导致请求期间保存按钮被禁用。修复后监听实际文本变化，网络请求只限制重复获取，允许先完成本地保存。

保存栏在普通编辑页面持续显示。失败原因显示在按钮附近，保留草稿；成功后重新读取磁盘。未读取配置或存在待恢复事务时显示对应状态。

移除账号登录、桥接启动、HTTP / WebSocket 转发、网关与代理控制及相关测试脚本。仅保留旧加密连接的读取与备份兼容，转换由用户点击保存触发；不因打开窗口写入配置。

验证使用虚构凭据和隔离目录：

- 61 项核心测试覆盖本地保存、回滚、恢复、外部修改冲突、旧连接转换、凭据遮盖与更新下载校验。
- 84 项隔离界面检查覆盖实际输入模型、地址与 PAT 后保存并重读、无在线服务保存、错误提示、旧连接转换与恢复、延迟模型请求期间先保存，以及布局、模板、托盘和开机启动。
- 延迟模型请求用例在原忙碌状态限制下失败，解除本地保存限制后通过。
- 窗口截图检查包含 PAT 表单、保存错误、最小尺寸、深浅主题和 100% / 125% / 150% 模拟缩放。

正式产物另执行实际发布程序 UI 检查、隔离安装卸载、源码与成品隐私扫描。测试不验证服务商的在线推理能力。
