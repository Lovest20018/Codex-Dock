# 0.15.0 实施审查

基线为 0.14.1 / `caae4bf`。完整实施用户确认的三个 UI 阶段，范围为 Web / 手机工作台和本机接入页；Windows 原生主窗口没有改版。

## 实现边界

Dock 自有 JS / CSS 位于 `src/CodexMobile/ui/`，在已有静态资源响应后追加，随冻结 worker 分发。上游公开 URL、脚本顺序、固定静态白名单、认证、CSP 和 CSRF 规则不变；上游快照清单保持固定，七项显式 overlay 各自记录原因和摘要。未增加依赖或前端框架。

发送前后和消息队列只提供可选展示回调，仍使用原 pending、receipt、内容版本及账号 / 网关 / 主机 / 聊天范围。相同待确认 payload 打开既有消息管理，核对属于只读操作。明确未提交才能进入修正重试；已接收与任务执行结果分别显示。快捷键检查 `isComposing` 和兼容的 229 键值。

设置与本机管理复用原控制器，通过 DOM 分组保留处理器。外观重置使用原浏览器默认值；共享通知和网关开关显示其范围与保存进度。本机 API 表单切页不销毁草稿，取消才重置。查看连接仍使用原读接口；退出、启动、切换与远程写入边界保持原样。

## 验证

- 生产 Dock 页面 17 项交互回归，五种宽度、亮暗主题、24px 消息字号、200% CSS 布局缩放；包含 IME、拒绝、排队、未知请求不重复、迟到确认保留新草稿、表单保留、焦点返回和文件 / 终端合成标签保留。
- 原生产发送流程 25 个场景及状态故障 / 手动刷新界面；账号、聊天切换、多次修改、HTTP 与 receipt 竞态沿用定向回归。另有 10 项草稿 / 轮询源码检查。
- 上游全量 Node 1,315 项、宽窄屏浏览器 66 项；Python 适配 / 真实隔离 HTTP 26 项，浏览器认证 / Android 宿主注入 / QR 五项；核心 81 项。
- 长列表 / 长聊天比较和测量方法见 [UI 实施记录](ui-optimization-plan.md)，本机中位数差异在 1.2ms 内；未声称网络提速。
- 发布程序由打包脚本执行 108 项隔离 UI 检查。安装验证比较全部文件、检查旧入口清理、卸载保留用户文件及真实注册表 / 用户环境未改变。归档、运行时资源和四项 SHA-256 另行核验，以包旁 verification JSON 和包内 UI report 为实际证据。

所有交互使用虚构凭据、合成内容和隔离数据目录，发送请求被拦截。没有操作真实账号、发送真实消息、安装到用户当前版本或推送发布。Chromium 中的 Android 宿主注入检查不等于真机 WebView；原生 Android / iOS 键盘、系统返回、安全区、系统缩放及真实 SSH / WSL / 模型任务未验收。
