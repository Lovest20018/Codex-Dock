# Windows 0.19.2 模型目录保存修复审查

当前已保存目录没有服务新增加的模型时，固定审核校验会阻止更改主模型；旧的“获取服务模型”只保留模型名称，没有更新保存时使用的原生能力。修复保留服务声明的原生描述，经连接身份核对后暂存进同一配置草稿。确认页列出主模型、独立审批覆盖、不可变能力目录与管理记录，确认后由原有事务统一备份、写入及核对。

服务快照保留模型内的能力和未来字段，只对非审核模型固定 `auto_review_model_override=codex-auto-review`。缺少原生结构、选中主模型或 API 可用审核模型时拒绝保存；未添加基于模型名称的能力推断，没有网络失败时关闭审核的回退。

下载结果仅绑定本次读取的地址、密钥、协议、模式、代理及 HTTP 授权。模型选择可以在读取后改变；连接输入任一项改变立即丢弃旧能力，即使随后改回也不重新采用旧结果。读取任务仍有原有取消和工作区检查。文件导入优先使用明确选定的来源。

服务响应不预先写临时导入文件。确认后的能力快照位于现有内容寻址目录，并用自己的已确认摘要作为后续同步来源；服务有更新时需要再次主动获取。事务仅在路径、内容摘要和来源身份均一致时接受内存来源；普通外部文件仍核对预览后的来源变化，已有不可变文件被修改时停止覆盖。管理记录继续使用 v1，旧备份和回滚格式不变。
