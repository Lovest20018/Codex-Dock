# Windows 文件预览与帮助验收

本轮补齐 WinUI 的已保存文件预览、集中使用说明及当前目录入口。WPF 保留默认交付地位，安卓视觉仍按原安排后续处理。

## 行为与范围

“文件预览”读取当前配置目录的 `config.toml`、`auth.json` 及当前 Windows 用户的 `CODEX_AUTHAPI_BASE_URL`。主配置、Profile、方案和手机设置的未保存草稿均不参与；结果标明读取时间与目录，不能单独证明现有聊天采用的参数。原生适配器不读取全部环境变量或系统凭据，也不运行配置里的命令。

配置使用共享敏感路径规则递归隐藏环境值、请求头与令牌，HTTP/HTTPS 地址隐藏用户信息、查询与片段；重新序列化的 TOML 不带原注释或排版。普通布尔、数字、日期及数组保留。认证仅展示已知认证方式、三个凭据字段是否存在和其他字段数量，未知字段名、账号身份、令牌及其他内容不进入展示结果。环境项仅展示该单一变量的脱敏地址，非 HTTP/HTTPS 内容隐藏。

每份源文件最多读取 8 MiB，单项最多展示约 100 万字符并明确标记截断。配置、认证、环境分别显示缺失或无法读取，一项损坏不阻止其余项。读取支持取消，前后复核文件内容、环境值和目录；过期、变更或取消的结果不能回填。保存、备份恢复、工作区重读及切换目录清除旧快照；外部更改通过重新读取获取。脱敏内容可明确复制，仅供核对，不作为原文件回写。

当前目录区可查看文件、打开目录及复制路径，打开目录只针对已存在的当前完整路径，不自动创建目录。目录进程以独立参数传入路径。集中帮助提供开始配置、文件来源、Profile/方案、网关/手机、托盘/启动、恢复和更新七类可搜索主题；按钮跳转已有页面，不替代各页确认或保存。

WPF 与 WinUI 共享 `ConfigurationPreviewService` 的脱敏投影、`WorkspaceDirectoryService` 和 `DockHelpCatalog`。WPF 保存预览继续展示当前计划，含尚未保存草稿；WinUI 文件页展示重新读取的已保存磁盘快照，两者范围分别说明。
