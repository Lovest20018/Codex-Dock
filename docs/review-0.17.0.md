# Windows 0.17.0 配置更新与重启联动审查

本版更新本地配置资料、社区模板默认选择、HTTP 确认与保存结果页的桌面重启入口。Android 原生代码、版本与签名保持不变。

配置更新采用固定的 Superba alpha.15 资料及 Codex `0.168.0-alpha.4` 官方 schema，记录来源与摘要。1064 条定义包括父表和动态名称；版本标记不声明最早支持版本。新默认值不自动写入用户配置，保留历史字段及本机方案覆盖。

HTTP 确认使用当前 Windows 用户加密并绑定 origin，覆盖模型目录、HTTP 与 WebSocket 网关入口；排队请求在转发前重新读取确认，保存撤销后停止对应 worker。Codex 自行发送的直连请求仍由 Codex 控制，界面说明该边界。

重启对象限定为核验的桌面 GUI，核对完整路径、进程 ID 和启动时间。通过普通关闭消息等待退出，不强制结束进程；重启前和退出后比较当次已保存文件快照。启动显式传入配置目录与登录环境，取消、超时、外部修改或新实例出现时停止。CLI、IDE、WSL / SSH 与手机执行端不由该入口重启。

## 验证

功能提交前已完成核心 109/109、完整 WPF 144 项检查，包含原生 CLI、用户加密保存和回滚、HTTP 确认与撤销、来源读取、窗口与缩放、重启取消及文件冲突。桌面退出与启动使用独立 Windows GUI 测试程序；真实 Codex 桌面仅做只读识别。测试未修改真实账号和配置，未启动真实模型任务。

发布脚本回归 13/13 通过，覆盖按平台选择、版本标签、源提交、安装验收、校验清单与已公开版本保护；提交前源码隐私扫描通过。

0.17.0 正式发布由仓库按平台流水线从同一干净提交冻结手机后台、生成自包含 WPF、安装器及便携包，并执行发布 EXE 和安装后 EXE 的完整界面检查、运行中手机后台覆盖升级、其他安装位置隔离、逐文件散列比较、卸载和用户设置保留检查。流水线另运行发布脚本、核心、手机网关及 Web 状态回归；包内 UI 报告、安装验收附件和 release manifest 记录实际结果及源提交。仅验证通过后上传并核对 GitHub 附件大小与摘要，再公开稳定版。

没有验证真实桌面重启后的每个字段是否被既有聊天采用；需新建聊天核对执行端版本、项目、Profile 和组织要求。实体手机、公网入口及真实 SSH / WSL 任务不属于本版新增验收范围。
