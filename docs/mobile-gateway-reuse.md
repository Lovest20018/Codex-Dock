# 手机工作台复用方式

0.14.0 起，以固定上游 Codex Mobile Bridge 2.1.7 的完整 Codex 服务和 Web 为基础，替代 0.13.x 的文字精简实现。来源、所有覆盖文件及校验方法见 [UPSTREAM](../src/CodexMobile/UPSTREAM.md)。

Dock 的适配层仅负责 WPF 生命周期、原有 HTTPS 入口、本机控制、Codex 提供方范围与旧数据迁移。原上游会话、账号、WSL/SSH、文件、终端、通知和安卓更新模块直接复用。账号登记面板同样复用，托管在独立本机端口，凭一次性链接进入；公网 API 保留上游对电脑登记操作的限制。

没有合并第二套聊天服务或复制维护一套简化网页。上游原始散列和显式覆盖散列在每次冻结构建前校验；构建会带齐远程注入源码、证书根、ConPTY 与许可。其他 AI 提供方在适配层禁用，网络入口继续使用用户已有反代。

发送、停止、审批、Goal、文件和终端写操作继续使用上游的原生 owner、provider、cwd 和权限边界。历史阅读不自动激活执行端。旧版操作结果未知的 UUID 迁移进上游账本，不根据准备中的 turn 猜测成功，也不会自动重发。旧版草稿先确认账号再导入。

具体功能见 [功能对照](mobile-upstream-comparison.md)，接入方式见 [手机连接](mobile-connection.md)，验证证据见 [0.14.0 审查](review-0.14.0.md)。
