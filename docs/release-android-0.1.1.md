# Lovest Code Android 0.1.1

安卓应用更名为 **Lovest Code**，同步更新系统应用名称、首页标题、关于窗口与剪贴板标签；继续复用现有 Logo。Windows Dock 和电脑侧共享 Codex 工作台名称保留。

versionName 为 0.1.1，versionCode 为 2。包名 `io.github.lovest20018.codexdock` 和原签名沿用，可直接覆盖安装 Codex Dock 安卓 0.1.0 并保留应用数据。安装包更名为 `LovestCode-Android-0.1.1.apk`。

构建核验应用标签、版本、签名、对齐和 Logo 资源；沿用现有 Android 模拟器验收入口，不增加功能或修改聊天、文件、通知协议。使用方法与验证边界见 [安卓客户端说明](android-dock-shell-plan.md)。
