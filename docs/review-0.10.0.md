# 0.10.0 发布审查

审查覆盖本次完整界面改版、连接模式、名称备注、开机启动、托盘生命周期，以及新增 GitHub 更新和发布流程。

已修复前次 review 发现的概览焦点丢失、网关异步停止跨目录状态覆盖及 `-SkipPublish` 删除待打包目录的问题。更新安装器启动失败时现在恢复网关会话的可启动状态，避免失败后只能退出软件。下载进度绑定当前下载版本，防止后续检查覆盖更新对象时影响异步回调。

GitHub 更新限定正式版本与指定仓库的安装器、校验清单；检查版本比较、预发布过滤、缺失发布、第三方链接拒绝、校验成功、错误散列/不可信跳转拒绝及临时文件清理。安装前重新散列校验，并以只读共享方式持有文件直到启动安装器。

本地核心检查 64 项通过；新增更新入口在隔离 UI 中验证，不运行测试安装器。正式发布必须从已提交的干净工作区打包，manifest 记录源提交，并通过最终 EXE 的 UI 检查与安装后再次检查。

个人凭据与配置只在本地用于隐私比对，禁止输出值。发布源码与 Git 历史扫描通过；最终 payload 与源码 ZIP 继续由打包脚本扫描。禁止包含个人 auth/config、加密连接、备注、备份、测试运行目录和日志。发布不附带截图。

审查未发现剩余阻断项。真实系统 DPI、注销开机启动、真实上游推理/官方账号登录未执行；安装和卸载在工作区隔离目录验证，真实桌面快捷方式不被改动。首次 GitHub 发布完成后还需读取实际 latest Release 确认更新接口。
