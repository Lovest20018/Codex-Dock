## 边界与兼容

当前 app-server 不支持 `--profile`，指定 profile 的来源明确未知，不以主配置冒充。来源读取是新进程的快照，不等于已打开聊天的会话或全部组织策略。模型能力来自本地目录声明，远端实际支持尚需服务确认。

压缩事件检查上限 2 MiB，超限仍转发但计数可能不全；只统计本次网关进程流量。HTTP 200、配置允许 v2 或供应商名称均不作为最近成功压缩证据。没有验证真实 Krill 压缩、真实模型速度 / 费用、新安卓真机后台通知或当前安装环境。
