# Windows 0.17.1 模板应用审查

本版仅修正模板预览、选择、来源与旧上下文停用流程。没有修改连接认证、网关协议或 Android 原生客户端。

## 行为与边界

- 上游六项配方和本地用户方案分开预览。旧方案的读取与保存保留其原有来源，不自动标为新版 Superba。
- 未选中字段及已有草稿保持；确认页包含当前待写入修改，取消后撤回本次模板暂存并保留此前草稿。相同值不重复暂存。
- 停用方案写入明确的 `false`。上下文管理为表格式时，在改变草稿前阻止整表替换为布尔值；检查不依赖模板 ID，复制和自定义方案同样适用。
- 所有保存仍经过已有冲突检测、加密备份与恢复。未自动更改真实用户配置，不宣称远端服务支持旧实验字段。

## 验证

本地 Release 构建零警告、零错误；核心回归 111/111、完整 WPF 界面回归 151 项通过。覆盖六项配方实际写入、停用三项 false、认证与无关配置保留、重复应用、模板来源、取消草稿和精确回滚；目视核对最小窗口、确认差异和深色主题截图。

完整证据及可复现入口见 [模板修正与验收](template-application-fix-2026-11-11.md)。该轮未启用可选的真实原生 CLI 兼容检查，未测试真实上游模型服务。

代码复审发现的“复制停用方案绕过表格式保护”问题已修复并增加副本、内联表及 Krill true 值的回归；复审未发现其他发布阻断问题。

发布流程从已提交源码构建自包含安装包，再执行便携版与安装后界面验收、运行中手机后台覆盖升级、用户文件和注册表保持、发布隐私扫描及附件 SHA-256 校验。最终安装验收报告和提交清单随 Release 附件提供。
