# Windows 新版任务流程复查

本轮继续复查 [UI 整合](winui-consolidation-2026-11-17.md) 后的实际操作路径，修正页面定位、工作台状态和手机接入引导。没有增加一级导航或更改独立保存范围。

## 改动

- 重复选择当前页保留当前滚动位置；切换页面仍恢复各自位置。通过“选择模型”、配置搜索或错误引导进入指定字段时，明确的输入焦点优先于滚动记忆，避免字段被随后到达的导航滚动带出视口。
- 工作台分别展示实例退出受阻、应用失败、配置外部变化、保存后取消应用、增强可重试和完成状态。查看失败结果只跳转到结果页，不再次重启或强制结束实例；配置冲突跳到配置来源，但不自动执行本机来源读取。
- 主配置干净而 Profile、方案或手机设置存在独立草稿时，工作台提供直接继续编辑的入口。顶部待处理菜单仍保留全部独立修改。
- 手机设置确认保存且服务运行后，底部提供“下一步：连接与配对”。配对页根据未配置、未启动、草稿待保存、待检测和已检测状态说明下一步；检测和二维码生成均需明确点击。配对成功提示指向新的“授权设备”页，设备页也可直接返回配对。
- 关闭的全局错误、恢复和登录提示不再为表单保留空白行；顶部目录菜单左侧对齐。连接页在正常状态下留出更多首屏表单空间。

工作台与按钮从同一份下一步投影取文案和动作，避免显示的建议与点击后的行为不一致。原配置保存、身份、恢复、授权与网关启停服务保持不变。
