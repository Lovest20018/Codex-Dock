# Codex Dock 0.10.2

打开软件即可读取当前 Codex 的本地状态与配置。

- 概览新增 Codex 进程状态、配置目录与文件读取状态，并显示模型服务商、默认模型、凭据来源和存储方式。
- 识别已有自定义服务商的地址、环境变量凭据和 Bearer Token；打开软件时无需重新填写连接。
- 启动、重新激活窗口及每 5 秒检查本机变化。没有未保存内容时自动同步；有草稿时保留编辑内容，提示重新读取，并阻止覆盖外部修改。
- 配置临时被占用或写入不完整时保留上次有效视图，后续刷新恢复。仅修改普通设置继续保留已有服务商和认证文件。
- 源码和发布包继续排除真实 Krill Key、个人配置、认证、加密连接及备份。

概览显示所选目录中的本地配置。项目、profile 或会话参数可能覆盖这些值；进程状态与登录凭据读取结果不等同于任务执行状态或在线认证验证。

可通过「应用设置与帮助 → 软件更新」安装此版本，也可下载安装器，或完全退出旧版后解压便携包。
