# Windows 0.16.2 上游移植审查

审查对象为相对 0.16.1 的选择性移植与配套发布改动。没有发现阻断发布的代码问题；本次补齐发布 CI 中新增下载参数回归的入口，并核对正式包必须重新冻结手机网关及网页资源。

## 代码与行为

- 通知、布局和图片下载只引入必要的适配，没有整体替换 2.1.7 快照；1264 个上游已有文件及 25 项显式 overlay 校验通过。来源提交和文件摘要在 overlay 中登记。
- 图片仍由原登录、owner、host、会话及文件边界授权；下载要求同源并明确选择原图。原生端拒绝重复、编码别名与无值下载参数。
- 阅读状态仅在同一聊天的稳定节点键内恢复；新聊天不继承旧卡片状态。复制仍要求可信手势与原生确认。
- Unicode 模型 ID 共用一个验证器，保持长度、空白及控制字符限制。推理增量处理保留摘要优先、迟到开始事件不抹除数据和完成事件覆盖规则，限制索引分配。
- 原有登录锁修复、账号范围草稿、Codex-only、固定域名与未知写入不重放保持原契约。

## 源码及开发 QA 证据

Dock 后端 37 项通过；受影响上游 Python 258 项发现、254 项通过、4 项平台条件跳过；Node 89 项通过；Java 下载器 61 项检查通过。真实 Chromium 在 390/1280px 各运行 20 项阅读检查，覆盖原图保存、工作区图片、延迟 CSS 和首次复制；共同 Dock UI 回归 22 项流程及五种宽度通过。详细证据及跳过项见 [移植记录](mobile-upstream-backport-2026-11-09.md)。

正式发布额外要求 `scripts/package.ps1` 重新冻结网关和自包含 WPF 程序，执行实际 EXE 的隔离 UI 检查；`scripts/verify-package.ps1` 验证运行中网关覆盖安装、其他安装目录不受影响、设置保持、逐文件一致、安装后 UI 和卸载。发布附件中的 `installer-verification-0.16.2.json` 与 `release-manifest.json` 记录本次实际安装器的结果、源码提交、文件大小和 SHA-256；失败不公开版本。

测试使用合成账户、临时数据目录及隔离进程，没有部署到用户当前安装目录或启动真实模型任务。实体手机、WebKit、iOS、厂商省电策略与公网/真实 Codex、WSL、SSH 联调不在本轮已验证范围。
