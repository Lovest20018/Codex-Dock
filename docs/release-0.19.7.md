# Codex Dock 0.19.7

## Windows 界面

- 首页突出当前状态和下一步，模型、服务地址、配置名称和 Codex 状态按行显示。页头在窄窗口将配置目录和待处理修改放到标题下方。
- 高级工具按用途提供十个可整行打开的入口，随内容区宽度切换三列、两列或单列。Ctrl+F 可搜索工具和配置字段，窗口缩放时保留查询和焦点。
- 连接与模型页增加页签选中标记，分开服务认证与模型选择，保留窄屏固定核对区。开发预览双击会打开独立演示窗口。

## 自 0.19.0 以来的其他改进

- 首页可直接更换默认模型。首次连接可选择 ChatGPT 账号或服务商密钥，在同一页选择模型、核对差异并决定保存方式。
- 更新模型能力目录时核对来源和专用审核选项。重启 Codex 时优先走原生退出流程，并在窗口就绪后继续。
- 手机连接可在同一页保存服务和准备配对码。模型网关诊断分别显示上游请求 ID 与实际收到的最终响应 ID。
- Windows 包里的手机后台更新了聊天创建回执、附属聊天与延迟输出、交互图表和原生消息时间。 [手机后台与 Windows 0.19.6 说明](https://github.com/Lovest20018/Codex-Dock/blob/v0.19.7/docs/release-0.19.6.md)

## 覆盖升级

运行 Windows x64 安装器并选择原安装目录。安装器会请求当时运行的 Dock 正常退出，并停止同一安装目录的网关。若出现草稿提示，先在 Dock 中确认如何处理。使用便携 ZIP 时请解压到独立目录，并保留整个目录。

发布附件包含安装器、便携包、源码、SHA-256 和安装验证报告。 [验收范围](https://github.com/Lovest20018/Codex-Dock/blob/v0.19.7/docs/review-0.19.7.md)
