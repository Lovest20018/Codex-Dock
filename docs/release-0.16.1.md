# Codex Dock 0.16.1

- 修复软件内更新只停止模型网关、遗漏手机后台进程而导致安装文件被占用的问题。安装前先处理未保存修改，再停止当前配置的两个网关，等待后台进程完全退出后启动已校验的安装器。
- 手机连接的“后台服务”、连接与账号的“本地模型网关”均增加独立“重启”按钮；托盘菜单也可分别重启两个网关。
- 重启使用已保存设置，保留未保存草稿；手机登录和设备授权保持。重启期间连接会短暂中断。
- 应用设置和托盘增加“停止网关并退出”，方便手动更新。普通退出继续保留后台服务。
- 安装器兼容旧版遗留的手机后台：只对目标安装目录内、身份核对通过的手机进程发送正常停止请求，并等待实际退出；其他安装目录的网关继续运行。未能确认退出时中止覆盖并显示处理方法。

安卓客户端仍为 Lovest Code **0.2.2**，本次无需更新安卓。

本页只发布 Windows 安装器、便携包及其源码、校验和与验证报告。Android 使用独立的 [0.2.2 发布页](https://github.com/Lovest20018/Codex-Dock/releases/tag/android-v0.2.2)，以后按各自更新分别发布。

## 更新

等待正在执行的任务结束。备份程序目录、Codex 配置目录及 `%LOCALAPPDATA%\CodexConfig\mobile`，核对 `SHA256SUMS-0.16.1.txt` 后运行安装包。

从旧版升级时，建议先在“手机连接”点击“停止”，在“连接与账号”停止正在运行的模型网关，再退出 Dock。新版可在应用设置或托盘直接选择“停止网关并退出”。安装器的兼容处理不强制终止无响应进程。

更新后打开 Dock，启动需要的网关。便携包应完整解压到独立目录，保留整个 `mobile` 文件夹。个人配置、手机账号和设备记录不随安装覆盖。

回退时停止两个网关并退出 Dock，恢复 0.16.0 完整程序目录及需要恢复的备份。验证范围见 [审查记录](review-0.16.1.md)。
