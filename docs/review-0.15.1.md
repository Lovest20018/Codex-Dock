# 0.15.1 修复与范围收敛

基线为 0.15.0 / `b99abd4`，修复审查复现的三处问题，并按用户选择保留全部 Codex 能力、移除无关入口。

## 实现

设置面板使用 legend 的稳定 `data-i18n` 分类，不依赖翻译后的文字。投递错误仅在与当前错误文本相同时去重，新输入的超长或 Skill 校验始终可见。聊天“更多”去除旧的全局设置绑定标识，保留原会话菜单控制器。

Windows 导航与标题改为“连接与账号”。两个网关的状态按钮在页面外常驻，复用托盘的只读认证健康探测，按当前配置目录隔离，迟到响应不得覆盖新目录。健康响应失败后只探测已保存的回环端口：明确拒绝连接才认作停止，开放或无法确认的端口显示未知。状态刷新不调用 Ensure、不保存或覆盖草稿；原有混合连接自动启动策略保持。运行中只代表网关健康，不代表公网 HTTPS 或真实模型请求已验证。

Dock 自有 UI 隐藏上游 Codex Desktop 更新工具、其他 AI 偏好；旧 provider 选择回到 Codex。上游导航新增可选能力判断，在 Dock 不构建、不读取动态网络部署设置；默认上游行为保持。显式更新 overlay 散列，固定上游清单未变。公网更新与网络部署 API 继续经过既有认证 / CSRF 检查后返回 404，本机管理拒绝桌面更新动作。保留账号、审批、文件、终端、Git、通知和原生执行端协议。

安卓继续使用原 APK 加载 Dock 页面，没有构建新 APK，原生菜单和更新仍归旧 APK。独立壳建议与发布前提见 [方案](android-dock-shell-plan.md)。

## 验证

验证结果以本版包旁日志和 verification JSON 为准。定向覆盖英文冷启动及刷新、旧其他 AI 偏好、真实会话菜单、待确认 / 拒绝后的超长输入校验、上游更新和部署入口隐藏，沿用草稿保护和五种页面宽度回归。HTTP 回归核对相关 API 拒绝且未调用更新控制器。

实际 WPF 隔离检查覆盖两个独立 worker 的运行 / 停止状态、无可信健康响应的占用端口、刷新不启动服务和草稿保留，另检查最小窗口、缩放与亮暗布局。打包后重新检查发布 EXE、安装 / 卸载、归档字节、冻结资源和 SHA-256。没有操作真实账号、模型、当前安装或公网部署；浏览器宿主模拟不等于安卓真机。

提交前结果：Dock 页面 22 项、HTTP 26 项、核心 81 项、WPF UI 109 项、上游 Node 1,315 项、安卓宿主 / 认证 / QR 五项及草稿 / 轮询源码 10 项通过。隐私扫描与上游 1,264 文件 / 七项 overlay 校验通过。WPF 最小窗口和 100 / 125 / 150% 布局均通过，网关状态栏保持一行。

核验过程中更正了核心夹具对旧管理页标题的断言，改为检查实际标签页资源标识。首次 Node 运行有一个 Windows 临时目录清理争用，完整重跑 1,315 项通过，未改其原始断言。真实设备、独立安卓 APK、SSH / WSL 和模型任务未验证。
