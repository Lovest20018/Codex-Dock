# Android 0.2.3 审查

本轮为已验证的移动修复递增 versionName 至 0.2.3、versionCode 至 6，沿用包名 `io.github.lovest20018.codexdock` 和证书 SHA-256 `0c31e8dc7e29b7e835343db7551df5a505498959e87d4462f1b6bd9b5e72098e`。

审查确认独立通知使用已认证电脑 origin、流与事件标识；重复事件不产生新卡片，每张卡片的 PendingIntent 使用独立 data URI。打开聊天只清理旧版聊天卡片；收件箱显式清理仍可按原通知元数据处理。保留电脑静音、通知权限和用户通知渠道配置。

共享与自有布局等待 DOM 和可读同源样式，仍由原生版本握手控制菜单接管。图片下载保留当前电脑、Cookie、来源、重定向、临时文件和回调代际边界。首次复制仍依赖可信触摸，未降低 token、当前 WebView 或焦点校验。

开发 QA 在隔离 Android 14 模拟器运行 72 项检查，包括三张通知卡片、重复事件去重及静音、首次真实剪贴板复制、图片下载 URL、草稿与三页导航、旋转、键盘和离线返回。正式 APK 还须从干净提交生成，核对版本、非调试标记、既有签名及源码输入；具体提交、APK 摘要与签名结果写入发布 manifest。

审核源码时没有发现阻断发布的问题。Windows 网关需要配套 0.16.2 才能完整提供网页、图片保存和模型修复。生产 APK 不包含测试脚本或测试 instrumentation；实体手机、相机和厂商后台限制未验证。其他平台边界及回归记录见 [本轮移植说明](mobile-upstream-backport-2026-11-09.md)。
