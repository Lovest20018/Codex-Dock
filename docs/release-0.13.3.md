# Codex Dock 0.13.3

修复同一反代或 NAT 来源下，未登录访问者输错五次密码导致其他设备授权被删除的问题。失败登录现在只限制新的密码登录及配对；已有有效 Cookie 保持可用，跨后台重启和解除限制不变。手动撤销、IP 规则、授权过期和认证配置变化仍然生效。

手机连接页将自动封禁文案改为“已限制新登录”和“解除登录限制”。发布包新增 [Web / 安卓与上游功能对照](mobile-upstream-comparison.md)，逐项说明已保留功能、缺失能力及原 APK 仍显示但服务不支持的入口。本版不补齐上游工作台功能。

## 更新与回退

1. 在旧 Dock 页面或托盘停止手机网关，再退出旧 Dock。退出编辑器本身不会停止后台。
2. 备份当前安装目录及 `%LOCALAPPDATA%\CodexConfig\mobile`；备份包含敏感授权，留在本机。按包旁 SHA-256 文件核对安装包或便携 ZIP。
3. 安装新版，或完整解压便携包；保留整个 mobile 目录。个人 Codex 配置和手机数据不随包覆盖，域名、监听端口及设备记录格式保持兼容。
4. 打开新版并启动手机网关，检测 HTTPS 入口；手机刷新页面。已经被旧版删除的授权不能恢复，需重新登录或扫码。
5. 回退前先停止新版手机服务，再安装原版本；原版仍有共享来源失败登录问题。不要用旧程序覆盖运行中的 worker。

本地回归和安装验证以 [审查记录](review-0.13.3.md)、manifest 和 verification 中报告为准。未在本轮变更当前真实服务、设备授权、路由器或 FRP，也未完成安卓真机与真实 Codex 消息验收。
