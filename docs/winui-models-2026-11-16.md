# Windows 登录与模型设置迁移记录

本轮为 WinUI 开发预览补齐官方登录读取、服务模型发现与模型行为设置。WPF 仍为默认交付入口；安卓应用资源未修改。

## 本轮行为

- “官方账号 + API 服务”可以读取原生 Codex 在当前目录写入的官方登录，或明确选择本目录的加密登录备份。当前身份优先，备份只暂存，确认保存后使用。读取保留服务密钥、主模型、备注、行为及能力目录草稿；冲突、取消或读取期间出现新身份时不采用旧结果。放弃草稿和切换目录会清除暂存凭据。
- “获取服务模型”仅读取当前服务目录。结果不自动选择模型；支持取消，连接发生变化时拒绝旧结果。空目录和请求失败保留原选择，选择结果后仍须确认保存。
- 新“模型与行为”页设置主模型、推理、摘要、详细程度、服务档位、搜索、Fast/Ultra Fast、上下文管理、沙箱与审批。与连接页共用一份草稿和保存确认。未设置值跟随 Codex，保留原有未知值与结构化审批规则。
- 专用审核、原生能力目录导入、读取客户端目录和同步全部先加入草稿。沿用 Core 的主模型覆盖和审核能力校验，通过确认后同时备份并写入配置、目录和管理记录。
- WPF 与 WinUI 共用 `OfficialLoginService` 和 `ModelDiscoveryService`。读取无写入副作用，保存继续通过 `ConfigurationSaveService`；新版不增加独立的文件事务或进程管理实现。
