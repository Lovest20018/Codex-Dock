# Codex Config 0.8.0

本版把配置说明和模板操作改成更短、更直白的界面。

- 左侧增加“配置模板”，常用设置、服务连接、模板、备份恢复入口统一。
- 设置项默认只显示一句用途；详细内容放在“了解更多”。
- 模板支持新增、编辑、复制、删除、恢复内置模板，以及把当前设置保存为模板。
- 模板保存在本机应用数据目录；跳过模型连接、认证和可识别的密钥字段。
- 模板只加入草稿，点击“保存配置”后才写入 Codex。
- 保存栏显示“有几项未保存”，说明文案改用“默认、当前值、应用所选项”等常用词。

升级时可直接覆盖安装。已有 Codex 配置和备份保持原位置；模板库位于 `%LOCALAPPDATA%\CodexConfig\templates.json`，旧版本无需迁移。备份或搬到其他电脑时可单独复制此文件。
