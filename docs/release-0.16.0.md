# Codex Dock 0.16.0

- 配置目录更新到核查内核 `codex-cli 0.166.0-alpha.5.1`，补入 20 条官方 schema 路径，共 1003 条定义；记录来源、日期与摘要，修正生命周期和参考默认值。
- “已配置”直接展开实际 MCP / 供应商等实例，支持含点名称与多个实例；增加结构化添加表单，明确“取消本文件覆盖”。
- 增加权限、认证、MCP、模型推理与服务档位组合校验；细分审批使用独立表单，保存前检查必填项。
- “来源与 profile”可读取本机执行端和项目的配置层，分列文件值、执行端值与来源；凭据遮盖。当前核查内核不支持 app-server 的指定 profile 读取，界面显示未确认。
- 独立 `<名称>.config.toml` 支持普通设置预览、保存、加密备份、冲突检测与恢复；日常 high / 复杂任务 xhigh 模板仅修改所选推理强度。
- 模型网关补齐 HTTP / SSE / WebSocket 的 v2 压缩诊断，区分请求、返回条目与确认完成；增加排队、上游响应头、首数据与总耗时。指标仅统计当前网关进程，不保存聊天或压缩正文。
- Windows 和 Web 增加手机完成提醒与安卓通知引导，不自动启用通知或后台常驻。

配套安卓仍为 Lovest Code **0.2.2 / versionCode 5**，使用原包名及证书，从相同提交重新构建；原生功能不变。已有 0.2.2 用户可继续使用，工作台的新引导随电脑网关更新加载。

## 更新与回退

等待任务结束，停止手机网关和模型网关并退出 Dock。备份原程序目录、Codex 配置目录及 `%LOCALAPPDATA%\CodexConfig\mobile`，核对 `SHA256SUMS-0.16.0.txt` 后运行安装器或完整解压便携包，保留整个 `mobile` 目录。更新后重新启动需要的网关并刷新手机页面。

本版不会自动改写现有配置、切换 profile 或启用实验项。模型网关诊断协议升至 4，旧进程由现有版本检查策略在下次启动时更新。回退时先停止两个网关、退出程序，再恢复 0.15.1 完整程序目录与需要恢复的配置备份。独立 profile 使用文件不影响未选择它的主配置。

开发验证为核心 94 项、WPF 119 项、Web 22 项流程及五种宽度通过；发布流水线会另验实际安装包和签名 APK。未用真实模型或账号进行费用、速度或压缩成功验证。指定 profile 来源与超大事件的诊断限制见 [完整实施记录](https://github.com/Lovest20018/Codex-Dock/blob/v0.16.0/docs/configuration-implementation-2026-11-02.md)，发布核验范围见 [审查记录](https://github.com/Lovest20018/Codex-Dock/blob/v0.16.0/docs/review-0.16.0.md)。
