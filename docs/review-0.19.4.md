# Windows 0.19.4 覆盖安装退出修复

旧安装器在复制前处理手机后台，主窗口由 Inno Setup 请求关闭。WinUI 把普通关闭解释为收起托盘。模型网关又由相同的 `CodexDock.exe` 启动，即使界面已经退出也可能继续占用文件。

安装器现在按安装路径、Windows 会话及用户核对进程。先调用 Dock 的正常退出流程，再用已保存的本地控制凭据核对并停止同目录的两个网关。旧 WinUI 可通过现有“设置 → 启动与窗口 → 退出程序”入口退出。退出请求或网关校验失败时，安装停在准备阶段，并显示可继续操作的位置。

安装验证在隔离目录运行托盘窗口、模型网关及手机网关，并在另一目录启动同类进程。核对目标进程已退出、另一目录的进程仍可用、配置与登录摘要匹配，以及安装后窗口检查和卸载。安装器和校验记录由原打包流程生成。
