## 行为与边界

- 直连只生成 `auth_mode=apikey` 与 `OPENAI_API_KEY`；清理旧 PAT、`chatgpt_base_url` 和用户级 `CODEX_AUTHAPI_BASE_URL`，选择文件凭据。普通设置保存不改认证。
- 迁移、切换和恢复均通过原有差异确认、外部修改检查、原子保存、加密备份与失败回滚。不会因读取、预览或切页改变真实认证。
- 当前官方登录优先于暂存的旧备份；没有当前登录时，需要明确选择本目录的备份。Dock 不发起设备码、浏览器回调或 CLI 登录，也不自动恢复已退出的账号。
- 两种服务类型与两种连接方式分别处理。API Key 直连无需本机模型网关；混合连接需要已保存的模型连接与运行中的网关。手机网关独立管理。
- 自动启动开关默认关闭，只在本次 Dock 启动时尝试一次。刷新、切页、保存配置及定时轮询不启动已停止服务；一个网关失败不阻止另一个启动。
- Windows 启动项与网关启动项分别设置，并明确关联程序路径及配置目录。测试使用隔离目录、虚构凭据和内存启动项。
