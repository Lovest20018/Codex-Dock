# Windows 0.19.1 正常重启修复审查

原普通退出使用 `WM_CLOSE`。当前已安装的 Codex 会把关闭窗口解释为收起到托盘，因此旧主进程仍在，Dock 按保护规则阻止重复启动并报告退出超时。

新实现复用固定上游手机运行时中已打包的 `codex-quit-helper.exe`，不修改固定上游源码。Core 在异步退出流程中传递主进程 ID、创建时间、程序路径与取消标记；组件通过 UI Automation 调用唯一的 Codex 退出菜单，不发送全局按键。隐藏或最小化时，Core 先核对唯一可信主窗口，再通过同一资料目录的单实例唤回恢复 Electron 内部可见状态。唤回程序须及时退出，原主进程身份和资料目录须保持一致，且不能出现新的独立主实例，随后才调用退出组件。

组件回执不代表应用已退出。Core 继续核对所有已捕获的主进程与后代，全部退出后才重新检查配置、安装文件及其他资料目录并启动。退出命令已发出但回执中断时只观察结果，不重放。用户取消时终止的仅是本次退出组件；目标 Codex 的强制结束仍通过原有单独确认分支。
