# Codex Dock 0.9.0

2026-10-28，测试构建。

## 连接信息

连接页新增可选的“连接名称”和多行“备注”，自定义服务与内置线路都可填写。点击“保存配置”后持久保存，概览显示已保存的名称和备注。只改名称和备注无需重填凭据，也不重写模型路由或认证。

信息随当前 Codex 配置目录保存到 `codex-dock-details.dat`，使用当前 Windows 用户加密保护，并参与保存前备份、冲突检查、失败回滚和恢复。不向 `config.toml` 添加服务商不支持的字段，不导入普通设置模板。本版仍编辑当前单个连接，未引入多个连接档案列表。

连接模式下方明确提示“PAT / API Key”无需登录 ChatGPT。切回 PAT：选择该连接模式，在更多连接选项中选择“PAT 中转”及“PAT”，填写服务商地址和凭据，保存后重新打开 Codex。

## 开机启动

“应用设置与帮助”新增“登录 Windows 后自动启动”，默认关闭。开关立即保存，不进入 Codex 配置草稿。仅登记当前 Windows 用户的启动项，不要求管理员权限。

启用时记住当前程序位置与配置目录。登录 Windows 后收起到托盘，网关按已保存连接启动；托盘创建失败时保留窗口。手动再次运行会恢复已有窗口，重复的登录启动不会弹出窗口。

便携版需要保留原文件夹位置；移动后可在新位置重新开启此选项。切换配置目录后，如需改用新目录自动启动，请关闭再开启。若 Windows 单独禁用了启动项，还需在 Windows 的“启动应用”设置中启用。安装包覆盖原路径时保持已有设置，卸载仅清理指向本安装目录的启动项。

## 验证

核心检查覆盖连接信息的独立保存、加密、普通编辑保留、删除恢复、并发冲突、失败回滚和旧备份兼容；启动项只在独立临时注册表键验证，并通过 Windows 命令行解析函数检查空格及路径末尾反斜杠。

界面检查使用虚构凭据、隔离配置目录和内存启动项，覆盖名称备注、概览、PAT 切换、即时开关、托盘启动与单实例唤回。未为当前用户开启真实开机启动，未注销或重启 Windows；DPI 检查继续使用布局缩放模拟。
