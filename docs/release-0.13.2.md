# Codex Dock 0.13.2

手机连接无需再填写反向代理来源 IP，支持群晖、FRP 与路由器端口映射。

- 移除手机页的代理来源字段及后台来源 IP 白名单。手机 HTTP 端口接受所有 IPv4 接口的连接，默认 `13090`，仍可手动修改。
- 保留配置域名的 Host、Origin、CSRF、独立密码、一次性扫码和设备撤销。私有管理端口始终只监听本机。
- 旧版手机设置自动兼容，原账号、密码、实例和安卓设备授权继续使用；旧代理 IP 不再限制连接。
- 远端转发头不作为可信客户端地址。登录失败限速及设备 IP 使用实际连接来源，因此同一代理可能共用限速，设备列表可能显示代理或 NAT 地址。

升级前在旧 Dock 手机页停止服务并从托盘退出，复制 `%LOCALAPPDATA%\CodexConfig\mobile` 到备份位置，再运行新版安装器或完整解压便携包。打开手机页，保留原 HTTPS 域名、账号与端口，密码留空沿用，点击“保存并启动”，再“检测 HTTPS 入口”。

例如外部入口 `https://codex.example.com:888`，群晖目标为 `http://公司公网IP:13090`，路由器将该端口映射到 Windows 电脑。反向代理保留外部 Host `codex.example.com:888`。公司公网 IP 是目标地址，无需作为代理来源填写。程序不自动修改路由器、FRP、证书或防火墙。

回退时先停止新版手机服务，再运行原版本。加密数据格式保留兼容，但 0.13.1 不认识新版协议号；需要时可恢复升级前的 `%LOCALAPPDATA%\CodexConfig\mobile` 目录备份。个人 Codex 配置无须覆盖。

验证结果与实际部署边界见 [0.13.2 审查](review-0.13.2.md)，详细步骤见 [手机连接说明](mobile-connection.md)。
