# Lovest Code 0.2.7

- 电脑列表保留上次连接检查的状态与时间。连接失败时显示证书、登录、超时或服务端错误，并可直接重试。
- 修改电脑地址时保留名称和已清空的通知状态，移除电脑时清理该电脑的偏好。深浅主题使用与 Windows 对齐的绿色强调色。
- 自 0.2.5 起的改进还包括在电脑页扫码、连接探测时返回列表、聊天图表全屏预览、追问加入草稿和聊天输入框的斜杠命令。图表等聊天功能取决于 Windows 手机网关和执行端的能力。

应用 ID 为 `io.github.lovest20018.codexdock`，内部版本号为 10。使用发布页的 SHA-256 校验 APK，然后直接覆盖安装以保留已有电脑、授权和草稿。建议和 Windows Codex Dock 0.20.0 一同使用。 [验收范围](https://github.com/Lovest20018/Codex-Dock/blob/android-v0.2.7/docs/review-android-0.2.7.md)
