# Codex Dock 0.13.0

新增 **手机连接** 页面，复用 Codex Mobile Bridge 的 Codex IPC、认证与一次性配对协议。使用已有 HTTPS 根域名，在上游安卓 App 扫码或通过独立账号密码登录，继续电脑上打开的 Codex App 聊天。

- 默认监听 `127.0.0.1:13090`，端口可手动修改；支持自定义 HTTPS 端口、入口检测、服务启停、配对二维码和设备撤销。
- 手机访问独立保存，不修改 Codex 的官方登录、模型路由和原聊天权限。
- 保留文字历史、发送、补充、停止及支持类型的原生审批；结果未知时不会自动重复提交。
- 安装器和便携包包含独立手机 EXE、Python 运行时与许可文件，无须另装 Python。
- 仅保留 Windows 本机 Codex App；不引入其他客户端、SSH、CLI 启动、终端、账号池或穿透管理。

升级前停止手机服务（旧版 0.12.x 无此服务），从托盘退出 Dock，再安装或完整解压新版。模型连接无需重新保存。便携版保留整个 `mobile` 文件夹。

34 项手机 Python 回归、79 项 .NET 回归和 10 项浏览器/二维码检查通过，桌面隔离 UI 检查通过。尚未进行安卓真机、公网登录或真实聊天操作验收。接入步骤见 [手机连接说明](mobile-connection.md)，证据和限制见 [版本审查](review-0.13.0.md)。
