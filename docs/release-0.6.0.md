# 0.6.0 配置编辑器精简

- 保留 PAT、API Key、Krill 三条线路、自定义服务和默认模型。
- 模型获取仅请求所选入口的 `/models`，删除身份/账户探测、自动接口回退与版本扫描。
- 界面收为连接配置、配置编辑、备份与恢复三页；常用项合并为配置编辑页的筛选。
- 本地 `config/config-schema.json` 替代四版本字段目录，删除外部仓库同步脚本及构建依赖。
- 支持未收录字段、加入新字段草稿，以及带引号的 TOML 键路径。
- 只改普通配置或模型时保留认证文件和用户环境变量；修改连接时继续统一写入三个位置。
- 保留加密备份、并发修改检测、失败回滚和未完成事务恢复。
- 移除 PAT 测试基线的创建与专用撤回；兼容旧备份/未完成日志。
- 清理上游源码、独立插件、客户端诊断、历史 UI 研究和中间产物。0.4.0 / 0.5.2 安装器与源码及独立插件源码归档在发布产物目录下。

## 检查

核心回归覆盖 PAT/API Key、精确接口请求、配置源文保留、未知及引号键编辑、无凭据配置保存、只读认证文件、加密备份、外部修改保护和失败回滚。

UI 检查在独立配置目录与内存环境变量中执行，覆盖新增字段、无凭据保存、线路、枚举/数组/文本编辑、搜索、草稿、恢复、缩放、主题和真实用户环境不变。发布脚本要求报告对应当前发布 EXE 的 SHA-256。

复杂表数组没有完整编辑器；字段表是静态说明，不读取 Codex 的最终生效配置。PAT 连接便利性保留，保存和模型列表读取均不等同于账户能力验证。
