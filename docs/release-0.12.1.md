# Codex Dock 0.12.1

修复使用 ChatGPT 登录时可能提示“未找到原生 codex.exe”的程序发现问题。

- 自动发现正在运行的原生 CLI、桌面版版本化运行时、独立 CLI 和 npm 原生包；读取当前进程、用户及系统 PATH，兼容安装后尚未刷新的环境。
- npm 支持当前平台包与旧 vendor 布局，不执行 cmd/PowerShell 包装脚本，不扫描整个磁盘。
- 找到程序后显示实际路径；找不到或手填路径已失效时，自动展开并定位程序选择栏。
- 保持 0.12.0 的混合连接、默认 PAT 编辑、网关和保存行为。

78 项核心回归通过；本机验证在 PATH 为空时仍能找到桌面版运行时，并执行 `--version` 成功。界面验证覆盖路径显示和失败时自动展开，不触发真实登录。原有功能和真实线路边界仍见 [0.12.0 审查](review-0.12.0.md)。

更新前从托盘退出旧版工具，安装后重新打开。无需修改或重新保存现有 Codex 连接；点击登录时自动重新查找程序。也可手动选择完整原生 `codex.exe` 所在位置，保持它与原运行时文件一起使用。
