# Codex Dock 0.14.1

修复消息发送成功后输入框仍保留原文的问题。移动光标不再被当作内容修改；发送期间才取得账号身份时，只清理本次已确认的草稿。新输入、引用、Skill、发送模式以及其他账号和聊天中的草稿继续保留。送达结果未知时保留原请求 ID，不自动重发。

Web 后台读取客户端状态遇到同一故障时只提醒一次，重试间隔逐步增加至 60 秒；成功读取后恢复正常轮询。应用管理保留错误与“刷新状态”按钮，手动刷新立即执行。退出登录或切换状态版本后忽略旧请求的错误。

## 更新与回退

1. 从页面或托盘停止旧手机网关，再从托盘退出 Dock；关闭窗口只会收起到托盘。
2. 备份安装目录、Codex 配置和 `%LOCALAPPDATA%\CodexConfig\mobile`，备份留在本机。
3. 核对 SHA-256，运行安装器或完整解压便携包；保留整个 `mobile` 目录。
4. 启动手机网关，在 Web 浏览器强制刷新页面，核对历史和草稿，再继续任务。
5. 如需回退，先停止新版网关并退出 Dock，再恢复旧程序。0.14.0 与本版的数据协议相同；回退后会再次受到上述两个界面问题影响。

本版没有改动账号、反代、端口或发送协议。后台状态读取的超时仍可能由实际网络或执行端故障引起；本版修复持续故障期间的重复打扰和重试频率，不承诺排除所有公网故障。验证与局限见 [审查记录](review-0.14.1.md)。
