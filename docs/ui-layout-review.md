# Codex Dock 界面布局检查与修整

2026-10-28。

## 检查结果

实际界面与隔离截图中确认了以下问题：

- 模板与备份的横向页签没有限制垂直对齐，按钮被拉伸到页面高度并覆盖正文。
- 配置目录允许换行，长路径会推低标题和内容。
- 固定侧栏在小窗口与高缩放下挤掉底部入口。
- 模型选择、搜索栏和设置分别占据固定区域，缩放后设置列表几乎没有可用高度。
- 设置项固定使用左右两列，窄窗口时中文标签、说明与输入框互相挤压。
- 页面缺少统一的内容边界，连接、模型、模板和网关的留白与对齐方式不一致。

## 本次修改

保留 WPF 与现有配置、登录、网关实现。将页头路径限制为单行省略，完整目录保留在悬停提示和配置位置面板中；侧栏导航独立滚动，底部入口保留；缩小时减少侧栏宽度。模板页签固定在顶部，加入正文不重叠的回归断言。

模型选择、搜索和设置现在共用一条页面滚动区域，窄窗口的字段改为上下排列。保存栏会在窄窗口中自动分行。概览、表单、模板与网关使用一致的浅灰画布、内容面板、间距、导航图标与深色配色。网关启停操作移到状态标题之后。

这次发现的问题均能在现有控件和布局中修复，暂不迁移前端技术栈。若后续确定要做跨平台版本，再单独评估界面框架与原生配置服务之间的边界。

## 验证

- Release / win-x64 自包含发布成功。
- 对发布目录中的程序执行完整隔离界面检查，69 项检查通过。
- 七个页面分别在 960 × 640 下进行 100%、125%、150% 布局缩放检查，共 21 张额外截图；缩放通过 WPF LayoutTransform 模拟，未修改系统 DPI 设置。
- 对长路径单行、侧栏底部位置、保存按钮边界、模板页签不重叠、模型页可滚动区域加入断言。
- 人工查看浅色、深色、连接、模板编辑与缩放截图，修复截图中发现的页签拉伸问题后重新发布并验证。
- 保存、恢复、模板草稿、官方身份保留、代理与网关、托盘关闭和退出继续通过原有隔离检查。示例凭据与目标目录均为测试数据，检查包含真实用户环境变量未改变的断言。
