# 0.10.3 启动连接加载审查

原流程在窗口 Loaded 后先初始化托盘，再读取连接。改为构造窗口时填好本地配置，普通打开时将托盘和首次网关检查延后到首屏绘制后；构造过程中不启动网关。

独立审查发现托盘启动不能等待首屏绘制；已保留开机启动时同步创建托盘并隐藏窗口的时序。隔离测试调用实际桌面初始化流程，断言在让出首次绘制前已隐藏，且仍可恢复和退出。该断言在统一延后托盘的实现上失败，修正后通过。

只读测量本机配置：文件读取约 4 ms，预热后的连接解析约 10 ms。分段测量确认连接字段原先位于托盘初始化之后；这些耗时仅说明本机样本，不作为所有电脑的速度保证。

新增隔离回归用例：准备已有服务地址与虚构 PAT，在窗口 Show、托盘和状态轮询之前断言字段已经填入，且没有产生草稿。该断言在原流程上失败，修复后通过。完整测试继续覆盖自动刷新、草稿冲突、文件恢复、布局、托盘、网关与开机启动。

本次不修改 Codex 的认证协议或用户配置，CLI 的 401 报错未纳入修复范围。发布仍执行源码与成品隐私扫描。

最终本地检查：69 项核心测试、86 项隔离界面检查通过；核心注册表测试使用独立随机测试键，未修改真实开机启动项。
