# 模板应用逻辑修正（2026-11-11，Windows 0.17.1）

本轮基于 Windows 0.17.0 修正模板应用流程，对应 Windows 0.17.1。0.17.0 不包含以下变更。

- Krill 社区方案对应固定的 Superba `v0.1.1-alpha.15` 六项 PAT 配方，不再混入 `analytics.enabled=false`。旧上下文、历史笔记及隐藏警告仍默认不选；“选择全部方案值”可以明确选择全部不同值，下一步仍需核对差异并确认写入。
- 每项同时显示本地值、已有草稿、方案值和本次结果。不勾选表示保留当前值或草稿，不表示关闭功能。相同值不重复生成修改。
- 本地编辑过的方案显示“查看本版内置方案”入口，可以直接使用随本版提供的配方，不需要删除本地方案。读取或编辑旧方案保留原来源，不把旧配方标为新版来源。
- 新增“停用旧上下文与历史笔记”方案，将 `features.context_management`、`features.token_budget.enabled`、`features.token_budget.use_history_notes_extension` 三项明确设为 `false`。已有草稿默认保留，需要替换时明确勾选。
- 停用方案适用于旧布尔开关。上下文管理为表格式时，所有模板（含复制的方案）均拦截整表替换为布尔值，需在全部配置核对子项。选中的字段合并到当前文件，保存沿用差异确认、加密备份和恢复流程。

这里记录的是方案取值与写入行为，不保证远端服务支持旧实验字段。保存成功后按界面提示重新打开 Codex 并新建聊天核对。
