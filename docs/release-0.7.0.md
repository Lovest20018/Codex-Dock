# Codex Config 0.7.0

默认打开常用配置编辑。服务连接与配置模板分开，保留 Krill 线路和社区配方，同时将通用配置工具作为主界面定位。

## 本版变化

- 配置编辑提供“常用 / 全部 / 已修改”，显示作用简述；可展开查看取值、使用场景、适用条件、默认行为、关联设置及来源。
- 首批 16 条结构化说明覆盖常用配置、现有模板七项与连接字段；其余条目沿用明确标注的历史目录，未收录字段不推测作用。
- Fast 功能开关与服务档位分开解释；上下文预算不解释为账单上限。旧实验项标为当前版本待验证，并移出默认常用列表。
- 连接页先选服务商，再选该服务的线路。空白配置默认自定义服务，不选择第三方；凭据名称按认证方式显示。
- 已有登录认证显示读取状态；仅编辑普通配置不要求填写凭据，不改写认证文件或用户认证环境变量。
- 配置模板从编辑页进入，先展示包含草稿的当前值、模板值与变化。已有草稿默认保留，相同值不重复加入；实验项与隐藏警告需主动选择。
- 模板可单独撤销，恢复应用前草稿并保留其它修改与不同于模板结果的后续编辑。
- “查看更改”默认展示脱敏字段差异，并可切换完整配置、认证与环境变量预览。统一保存栏显示未保存项数。
- 返回编辑页保留搜索、分页和滚动；高级列表继续每页最多 30 项。单页结果隐藏翻页栏。

## 使用与更新

关闭旧版后运行 `CodexConfig-0.7.0-Setup-win-x64.exe`，或将便携包解压到新目录运行。无需另装 .NET。安装器仍使用当前用户安装，不迁移或导入任何模板。

默认读取 `CODEX_HOME` 或 `%USERPROFILE%\.codex`，安装和升级本身不修改用户 Codex 配置。正常保存前保留本地 DPAPI 加密备份；原有备份可继续恢复。

如需回退，关闭本版后运行保留的 0.6.1 安装包或便携程序。若已保存不需要的配置变化，可在“备份与恢复”恢复上次保存前的状态。恢复仍会校验外部修改并保留当前备份。

## 验证与限制

核心回归覆盖模板差异、同名草稿冲突、无效选择的原子校验、重复应用、单次撤销和认证保留。发行 EXE 在隔离目录运行界面检查；安装器另用 VERIFYONLY 模式验证安装文件、界面启动和卸载，不改写真实注册信息和用户认证环境变量。

界面检查包含最小 960×640 窗口、深浅色及 125% / 150% 布局缩放模拟；后者不等同于对所有显示器进行原生 DPI 实测。

配置作用说明按 2026-10-28 的官方文档和本地历史目录标注来源。配置格式校验和文件保存成功不代表所有客户端、模型、服务端都支持相应选项。当前工具不探测最终运行值、账户权益或计费。旧上下文管理、Token 预算及笔记扩展保留原配方供明确选用，未宣称其当前可用性。
